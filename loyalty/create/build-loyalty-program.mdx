Build a loyalty program using the Loyalty Programs module.

## About this task

Complete the following steps to build a loyalty program:

1. Complete prerequisite steps.
2. Create and name the loyalty program.
3. Configure the default tier.
4. Add and configure tiers as necessary.
5. Publish tiers and loyalty program.

## Step 1. Complete prerequisite steps

- Make sure that any point accounts and point sources needed for the loyalty program have been defined in the Points Management module.

## Step 2. Create and name loyalty program

1. Navigate to the Loyalty Programs dashboard and click **Create Program**.
2. On the Create Program dialog, name the program and click **Create**. Use a name that uniquely identifies the program in the SessionM platform.

## Step 3. Configure default tier

1. On the Tiers Definition page, rename the tier if you want. By default, the first tier is named "Tier Level 1." To rename the tier, click the Pencil icon and enter the new name.
2. Configure each rule set:
   1. For Rules to Enter Tier:
      1. Click **+Add Rule** to select the rule that determines the tier entrance requirements.
      2. Display Rules to Enter Tier panel. Indicate how often a member can earn the award for entering the tier.
   2. For Rules to Stay in Tier:
      1. Click **+Add Rule** to select the rule that determines the tier maintenance requirements.
      2. Display Rules to Enter Tier panel. Indicate how often a customer should be evaluated to remain in the tier.
   3. For Purchase Event Benefits, click **+Add Rule** to add a rule that governs purchase events. Select the rule from the list and click **Done**. Repeat until all rules have been added.
   4. For Other Event Benefits, click **+Add Rule** to add a rule that governs events that are not purchases. Select the rule from the list and click **Done**. Repeat until all rules have been added.

## Step 4. Add and configure tiers as needed

Add the additional tiers required for the loyalty program.

1. On the Tiers Definition page, click **+Add Level**.
2. Name the new tier.
3. Follow the instructions in "Step 3. Configure default tier" above to configure the tier.
4. Repeat this step to add the full set of tiers to your loyalty program.

## Step 5. Publish tiers and loyalty program

1. On the Tier Definition page, select a tier and click **Publish Tier**. Click **Publish** in response to the prompt. Repeat for each tier that you want available in the loyalty program.
2. Click **Publish Program** to publish the loyalty program.

**Note**: If you add new tiers or edit existing tiers after initially publishing the program, those changes are not visible to customers until you publish the tiers.
