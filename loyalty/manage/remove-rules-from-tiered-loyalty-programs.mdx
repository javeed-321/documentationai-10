---
title: "Remove rules from tiered loyalty programs"
description: "Remove or delete a rule from a tiered loyalty program using the Tier Definition screen."
---

Use the Tier Definition screen in the Loyalty Programs module to remove or delete a rule from a tiered loyalty program.

## About this task

Rules can be used in more than one tiered loyalty program. This affects whether you remove or delete a rule from a program.

- If a rule is used in more than one program, you are given the option to remove that rule on the Tier Definition page. This means that the rule, while the rule is no longer part of the current tiered loyalty program, its definition remains in the Rules Management module (because it is being used by another tiered loyalty program).

- If a rule is only used in the current program, you are given the option to delete that rule on the Tier Definition page. This means that the rule is no longer part of the current tiered loyalty program and, in addition, its definition is deleted from the Rules Management module.

## Steps

1. Navigate to the Loyalty Programs dashboard and click on the program name.

2. On the Tiers Definition page, select the rule that you want to remove or delete.

   - If the rule is used in other tiers in this program or in a different tiered loyalty program altogether, you are prompted to remove the rule. Click **Remove**.

   - If this is the only instance of this rule, you are prompted to delete the rule, with a reminder that deleting a rule cannot be undone. Click **Delete**.
