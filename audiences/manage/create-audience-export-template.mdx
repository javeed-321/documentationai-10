Create an audience export template in the SessionM Platform. Note that these templates are used for external campaigns built in the Campaigns Module.

## Steps

1. On the Audiences dashboard, click **Manage Exports**. The Manage Exports page opens displaying the Full Definitions sub-tab for the Configuration tab.
2. Click the **Templates** sub-tab. Any existing templates appear, each one displaying its name, format, destination, and creator.
3. Click **Add Template**. The template builder opens with the Setup tab showing.
4. Build the template following the instructions detailed in [Export Audience or Snapshot](/audiences/manage/export-audience-or-snapshot).

When you've completed building the template, it will display on the Templates sub-tab of the Configuration tab, within the Manage Exports page. If you want to edit an existing template, simply click <img src="https://docs.sessionm.com/Resources/Images/Assets/actionbutton.png" alt="Action button" class="inline-image" /> in the table row that contains the template you want to edit, and then select **Edit**.
