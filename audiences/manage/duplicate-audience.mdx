---

Duplicate an audience.

## Steps

1. From the All Audiences view of the dashboard, click <img src="https://docs.sessionm.com/Resources/Images/Assets/actionbutton.png" alt="Action button" /> in the table row that contains the audience that you want to duplicate, and then select **Duplicate**.

   <Image src="https://docs.sessionm.com/Resources/Images/Procedures/NEWdup1.png" width="758" height="281" alt="Quick action menu on an audience row with Duplicate selected" caption="" />

2. The Duplicate Audience dialog opens, displaying a default name for the duplicate audience. Modify the name if desired, then click **Save** to create the duplicate audience.

   <Image src="https://docs.sessionm.com/Resources/Images/Procedures/NEWdup2.png" width="567" height="262" alt="Duplicate Audience dialog showing the default name for the duplicate" caption="" />

The duplicate audience will now display in the All Audiences table in a draft state.
