Issue an offer to every member of an audience without having to create a campaign or define behavior events.

## About this task

SessionM provides two methods for issuing a bulk offer:

- **From the Campaigns module**: You can issue a bulk offer as part of a campaign. This methods allows you to schedule when you want the offer to go out and set it up to be recurring if desired.
- **From the Audiences module** You can issue a bulk offer to an audience at any time using the Audience module. This section describes that procedure.

## Before you start

- Make sure that the offer should has been defined in the SessionM Offers module.
- Make sure that the audience has been defined in the SessionM Audience module and that it is in the Active state.
- **IMPORTANT:** When issuing an offer to an audience from this tab, you must take a static snapshot **or** export the audience immediately before issuing the bulk offer. SessionM looks for the most recent object called 'audience generation request' to determine who to target for the bulk offer. Both of these actions (taking a snapshot or exporting) create this object, so you can choose to do either one of these actions. See [Create static snapshot](/audiences/create/create-static-snapshot) or [Export audience or snapshot](/audiences/manage/export-audience-or-snapshot) for the steps to complete these actions.

## Steps

1. From the All Audiences view of the dashboard, select the desired audience.
2. Select the **Offer Issuance** tab.
3. Click **Select Offer**.
4. On the Select an Offer dialog box, select the offer from the list and click **Select**.
5. On the Offer Issuance tab, click **Issue Offer**.

<Callout kind="info">
  The time that it takes for the offer to be issued to every member of the audience varies depending on the size of the audience. For planning purposes, SessionM recommends using a rate of 90,000 offers issued per hour.
