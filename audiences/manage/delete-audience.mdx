Delete an audience.

## Steps

There are two ways to delete an audience. Note that once an audience has been deleted, it cannot be undone.

### From the All Audiences view

1. Click the quick action button (three vertical dots) in the table row that contains the audience that you want to delete, and then select **Delete**.

   <Image src="https://docs.sessionm.com/Resources/Images/Procedures/NEW_delete1.png" width="581" height="213" alt="Quick action menu on an audience row with Delete selected" caption="" />

2. Click **Delete** to confirm the deletion.

### On an Audience page

This can be done from either the Details tab for an active audience or the Build tab for a draft audience.

1. Click the **Delete** button in the upper right-hand corner.

   <Image src="https://docs.sessionm.com/Resources/Images/Procedures/NEW_delete2.png" width="586" height="165" alt="Delete button in the upper right-hand corner of an audience page" caption="" />

2. Click **OK** to confirm the deletion.

Once an audience is deleted, it will no longer be listed in the table on the All Audiences view.
