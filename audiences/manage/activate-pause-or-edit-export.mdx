---
title: "Activate, pause or edit export"
description: "Change an export's status between active and paused, or edit the export, from any of three locations in the Audiences module."
---

Change the status of an export from active to paused or from paused to active. In addition, from the same location, you can choose to edit the export.

## Steps

You can activate, pause, or edit an export from three locations.

- **From the All Audiences view of the dashboard**, select the audience containing the export of interest. Click the Exports tab. If not already displayed, click the Configuration tab. Click <img src="https://docs.sessionm.com/Resources/Images/Assets/actionbutton.png" alt="Action button" /> in the table row that contains the export you want to activate, pause, or edit. Then select the desired action.

  <Image src="https://docs.sessionm.com/Resources/Images/Procedures/activate_1.png" width="780" height="156" alt="Exports tab with the action menu open on an export row" caption="" />

- **From the All Audiences view of the dashboard**, select **Manage Exports**. Then, if not already displayed, click the **Configuration** tab, which displays the Full Definitions sub-tab. Click <img src="https://docs.sessionm.com/Resources/Images/Assets/actionbutton.png" alt="Action button" /> in the table row that contains the export you want to activate, pause, or edit. Then select the desired action.

  <Image src="https://docs.sessionm.com/Resources/Images/Procedures/activate_2.png" width="779" height="160" alt="Manage Exports page showing the Full Definitions sub-tab" caption="" />

- **From the Setup tab of the export job builder**, you can pause or activate an export by moving the **Export Active** slider: red to pause; green to activate.

  <Image src="https://docs.sessionm.com/Resources/Images/Procedures/activate_3.png" width="780" height="398" alt="Export Active slider on the Setup tab of the export job builder" caption="" />
