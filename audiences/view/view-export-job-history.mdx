View the history for the export jobs for a specific audience or for all audiences.

## About this task

Each row in the table corresponds to a historical export and includes the following information:

- **State**: Whether the export was successfully completed or failed.

- **Name**: Name of the export.

- **Audience**: Specific audience that was exported (only displays when viewing exports for all audiences on the Manage exports page).

- **Type**: Type of export. This may be static or dynamic.

- **Cadence**: Indicates whether the export was created to only run once or be recurring.

- **Start Date**: When the export was scheduled to start.

- **End Date**: When the SessionM platform completed exporting to the file to its destination.

- **Format**: Format of the export. Most often exports are a CSV file.

- **Destination**: Where the file is being exported to. Destinations vary by environment. If you're not sure where to find your exports, reach out to your SessionM team.

- **Created By**: Who created the export. Hovering over the user's initials displays their full name.

- **Count**: Number of audience members in the export.

- **External ID**: Can be used as a reference within the SessionM platform if you are looking to find the export in other parts of the system.

## Steps for specific audience

1. From the Audiences dashboard, select the desired audience.
2. Select the **Exports** tab.
3. Select the **History** tab.

## Steps for all audiences

1. From the main dashboard, select the **Manage Exports** tab.
2. Select the **History** tab.
