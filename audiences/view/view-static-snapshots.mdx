View list of static snapshots for an audience.

## About this task

Each row in the table corresponds to a static snapshot that's been taken and includes the following information:

- **Audience**: Name of the static snapshot. You can always rename your static snapshot by clicking the quick action button <img src="https://docs.sessionm.com/Resources/Images/Assets/actionbutton.png" alt="Quick action button" class="inline-image" /> button to the far-right of the snapshot and selecting **Rename**.

- **Status**: You may see scheduled, in progress or completed here. Depending on the audience size, it may take a few minutes for a snapshot to process.

- **Audience Size**: Number of users in the snapshot. Because audiences are often dynamic in nature, the audience size will likely vary for snapshots of an audience taken at different points in time.

- **Created By**: Who created the snapshot. Hovering over the user's initials displays their full name.

- **Created On**: Date and time of when the snapshot will be created. If you schedule a snapshot to happen in the future, it will show that future date/time here of when the snapshot will actually be processed.

## Steps

1. From the All Audiences view of the dashboard, select the desired audience.
2. Select the **Static Snapshots** tab.

<Image src="https://docs.sessionm.com/Resources/Images/Procedures/view_static_1.png" width="780" height="254" alt="Static Snapshots tab listing the snapshots taken for an audience" caption="" />

Note that you can easily determine whether an audience has any static snapshots by referring to the Snapshots column from the All Audiences view.

If an audience has any static snapshots, you can click the number indicated in the Snapshots column for the audience. Doing so opens a window that summarizes the static snapshots and provides a More Details link that toggles open the Static Snapshots tab.
