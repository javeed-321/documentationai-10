---
title: Select your pre-defined attribute cards
description: >-
  Add standard and custom attribute cards to the audience builder and define the
  criteria customers must meet to be included.
---
1. Select an attribute that you want to segment your audience by from the Add Segment drop-down.
   <Image src="https://docs.sessionm.com/Resources/Images/Procedures/segment_options.gif" width="1508" height="552" alt="Selecting an attribute from the Add Segment drop-down" caption="" />
   - **Standard attributes** are populated in the dropdown list for you to select from. Note that you can search for a specific attribute by typing into the Add Segment field. Once selected, the attribute card will be added to the audience builder.
   - For custom attributes, select **Appended Data** from the dropdown. This will open the Custom Attribute Selector. With this, you can view the custom customer attributes set up in your environment. Select the attribute you need for your audience, then click **Add** to add the attribute card to the audience builder.
2. Once an attribute card is added, define the criteria a user must meet to be included in the audience. How you do this varies depending on the attribute card that was chosen – for some cards, you may select values from dropdowns, other cards you may enter text, adjust sliders, etc. to define the value(s) for the selected segment.
3. All attribute cards have an Include/Exclude toggle. By default, Include is enabled, meaning customers that meet the criteria you've defined for the attribute will be included in the audience. If you toggle to Exclude, customers that meet the defined values are excluded from the audience. This is useful, for example, if you don't want customers that live in Alaska or Hawaii to be included in your audience. Select the State attribute, select Alaska and Hawaii from the list, then toggle to Exclude. Customers that live in Alaska and Hawaii will now be excluded from the audience definition.
   <Image src="https://docs.sessionm.com/Resources/Images/Procedures/create_audience_5.png" width="624" height="287" alt="Attribute card showing the Include/Exclude toggle" caption="" />
4. Continue adding as many or as few segments as needed to define the audience. Be sure to refer to the next step ('Define the logic for your attribute cards') as you add segments.
