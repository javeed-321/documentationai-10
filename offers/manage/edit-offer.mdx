---
title: "Edit offer"
description: "Modify an existing offer. Editing changes the Offer ID and requires republishing, and only affects offers issued going forward."
---

Modify an existing offer. When an offer is edited, the Offer ID changes. It needs to be published again or else it reverts to draft status. Any changes made to live offers only update offers issued moving forward. Previously issued offers cannot be changed once recieved by the consumer.

## Steps

1. On the Offers dashboard, locate the offer that you want to edit.
2. Click **Edit**. You are taken to the Setup view.
3. Modify the offer as needed. See [Create Offer](/offers/create/create-offer/overview) for more information.
