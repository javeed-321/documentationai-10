---
title: "Configure Customers module"
description: "Use Customers 2 Settings to configure UI components in the Customers Module, including event streams, profile summary, navbars and quick actions."
---

This article provides instructions for using Customers 2 Settings to configure several UI components in the Customers Module (also called Customers 2 Module). You may want to modify components in the following ways:

- [Event streams for sub-tabs on the Activity tab (_activity/headers_)](/admin-and-rights/create/configure-customers-2-event-streams-for-sub-tabs-on-activity-tab)
- [Customer profile summary data for the active customer (_headers_)](/admin-and-rights/create/configure-customers-2-profile-summary)
- [Product recommendations and member profile sub-tabs on the main navigation bar (_navbars_)](/admin-and-rights/create/configure-customers-2-product-recommendations-or-member-profiles)
- [Quick actions that display for offers shown in sub-tabs on the Offers tab (_offers/quickactions_)](/admin-and-rights/create/configure-customers-2-quick-actions-for-offers)

In addition to the configuration options detailed above, note that you can rearrange the order of UI sub-tabs for any tab managed from the Customers 2 Settings page.
