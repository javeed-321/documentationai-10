Create a rendering template for the Timeline Series Config tool.

## About this task

A rendering template ties together a few important Timeline Series Config entities. The stream view, which contains the events in the stream designated for visualization, is matched with an event template. The event template provides the HTML code governing how the stream view events will be formatted and presented. The final entity is the rendering context, which specifies the type of activity being shown. For example, activities based on device type (mobile or desktop) or those that reflect a certain kind of user such as administrators or true end-users.

## Steps

1. On the Admin & Rights 2.0 dashboard, under Platform Configurations, click **Timeline Series Config**. The Timeline Series tool opens, displaying the Event Categories page.
2. From the navigation column, click **Rendering Templates**.
3. Then click **Create Rendering Template**.
4. In the New Rendering Template modal, specify the event template you want assigned to the rendering template.
5. Then, select the stream view and rendering context you want defined to the rendering template.
6. Finally, indicate a version for this rendering template.
7. Then click **Save**.

Once you save the rendering template, it displays in the Rendering Templates table.
