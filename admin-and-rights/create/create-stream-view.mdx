Create a stream view for the Timeline Series Config tool.

If you want to review a configuration workflow for the Timeline Series Config tool, which includes this task, see [Configure Event Stream with Timeline Series Config Tool](/admin-and-rights/create/configure-event-stream-with-timeline-series-config-tool).

## About this task

Stream views allow you to limit the events mapped to a particular stream. Rather than showing activity data from ALL event types - the results of which might be a data set that is extraordinarily large - you can constrain a subset of the events into a defined view. For example, the view for a customer member statement or, alternatively, a view for a customer service agent. Each view expresses its own collection of events.

## Steps

1. On the Admin & Rights 2.0 dashboard, under Platform Configurations, click **Timeline Series Config**. The Timeline Series tool opens, displaying the Event Categories page.
2. From the navigation column, click **Stream Views**.
3. Then click **Create a Stream View**.
4. In the Stream (Type) Name field of the New Stream View modal, begin by selecting the stream type you want shown in the stream view.
5. Now specify a name and description for the stream view you want to create.
6. If you want all of the event types associated with the stream shown in the view, leave both the Query and Grouping Field fields set to zero.
7. Then click **Save**.

Once you save the stream view, it displays in the Stream Views table.
