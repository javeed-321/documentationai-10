---
title: Configure Customers 2 event streams for sub-tabs on Activity tab
description: >-
  Specify which event stream is displayed in a particular Activity tab sub-tab
  from the Customers 2 Settings page.
---
This article provides instructions for specifying which event stream is displayed in a particular Activity Tab sub-tab.

## Steps

1. On the Admin & Rights 2.0 dashboard, under Module Configurations, click **Customers2 Settings**. The Customers 2 Settings page opens, displaying the sub-components of the first component listed in the page's navigation panel. If _activity/headers_ is not active, select it.
2. From the associated sub-components, or headers, select the header for which you want to configure an event stream.
   1. If you selected _activity\_log_, the following Component Details text box displays:
      <Image src="https://docs.sessionm.com/Resources/Images/Procedures/AdminRights/customers2_settings_component_details_event_stream_activity_headers_use_activ_log.png" width="300" height="164" alt="Component Details text box for the activity_log header" style="width: 300px; height: auto; cursor: pointer;" caption="" />
      1. Click **Is Event Stream Tab?** Then pick the slug (identifier) for the stream you want to display from the Event Stream View Slug dropdown.
      2. Click **Use New Activity Log?** to activate the event stream.
   2. If you selected any other sub-component, or header, this Component Details dialog displays:
      <Image src="https://docs.sessionm.com/Resources/Images/Procedures/AdminRights/customers2_settings_component_details_event_stream_activity_headers.png" width="340" height="146" alt="Component Details dialog for other activity headers" caption="" />
      1. Click **Is Event Stream Tab?** Then pick the slug (identifier) for the steam you want to display from the Event Stream View Slug dropdown.
3. Click **Save**.
