Create custom user profile attributes for customers.

<Callout kind="info">
  The Custom User Profile Attributes page supports the creation of custom attributes for customers - not to be confused with users (user accounts) configured to use the SessionM Platform UI.
</Callout>

## About this task

Custom attributes reflect the unique characteristics of an organization's customers. Often these attributes express information that can be leveraged for promotional campaign targeting. This type of data also reflects how customers engage with the program at an individual level.

Note that the creation of custom attributes is NOT to be taken lightly. Not only are new custom attributes unable to be deleted, but their existence can have profound effects on any associated downstream systems.

## Steps

1. On the Admin & Rights 2.0 dashboard, under Platform Configurations, click **User Profile**. The Custom User Profile Attributes page opens, displaying all of the existing user profile attributes.
2. Click **Create Attribute** to open the "Create a custom attribute" page.
3. In the Name field, enter the custom attribute's name.
4. From the Type dropdown, select the attribute's type. Depending upon which attribute type you choose, additional fields that allow you to further configure the custom attribute may display.
5. In the Filters field, add any filters you want applied to values for this custom attribute.
6. Click **Create**.

The new attribute appears in the table displayed on the Custom User Profile Attributes page.
