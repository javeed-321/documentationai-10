Edit any object configured in the Timeline Series Config tool.

## Steps

1. On the Admin & Rights 2.0 dashboard, under Platform Configurations, click Timeline Series Config. The Timeline Series tool opens, displaying the Event Categories page.
2. Click the Timeline Series object you want to edit, including:

   - Event Categories (the default object that displays)
   - Stream Types
   - Streams
   - Event Types
   - Rendering Contexts
   - Events Templates
   - Stream Views
   - Rendering Templates

3. Locate the object you want to modify in the corresponding table.
4. In the object's Actions column, click the associated **Edit** link.
5. In the edit modal that opens, modify the data in the appropriate field(s) and then click **Save**.
