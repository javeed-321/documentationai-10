---
title: About Admin & Rights module
description: >-
  Overview of the Admin & Rights module, where you administer the SessionM
  Platform across Management, Platform, Module and Integration areas.
---
The Admin & Rights Module is where you administer the SessionM Platform. It is organized into administrative areas, including Management, Platform Configurations, Module Configurations and Integrations. The module supports several different kinds of configuration, including:

- **_Accounts, Groups, and Roles_**

  Creating and maintaining user accounts, along with their groups and roles. For more information, see [About Accounts, Groups, and Roles](/admin-and-rights/about/about-accounts-groups-and-roles) as well as [Access Rights Workflow for Accounts, Groups, and Roles](/admin-and-rights/about/access-rights-workflow-for-accounts-groups-and-roles).
- **_SM Sync_**

  [Configuring ETL settings using the SM Sync tool](/admin-and-rights/manage/manage-sm-sync).
- **_Timeline Series Config_**

  [Setting up event streams using the Timeline Series Config tool](/admin-and-rights/create/configure-event-stream-with-timeline-series-config-tool).
- **_Messaging Providers_**

  Configuring and maintaining email, push, and SMS message providers, along with their associated message templates. To learn more, see [About Messaging Providers and Templates](/admin-and-rights/about/about-messaging-providers-and-templates). If you want procedural information, see [Configure Messaging Providers](/admin-and-rights/create/configure-messaging-providers) or [Configure Messaging Provider Templates](/admin-and-rights/create/configure-messaging-provider-templates).
- **_Organization Profile_**

  [Specifying settings for your implementation's organization profile on the platform](/admin-and-rights/create/create-organization-profile).
- **_User Profile_**

  [Creating custom attributes for customer profiles](/admin-and-rights/create/create-custom-user-profile-attributes).
- **_Affiliations_**

  [Configuring customer hierarchies](/admin-and-rights/create/configure-affiliations).
- **_SSO & SAML_**

  [Configuring SSO and SAML settings for SSO providers](/admin-and-rights/create/configure-sso-and-saml-settings).
- **_Customer Search Configuration_**

  Defining search and search results UI attributes for the Customers Module. To learn more, see [About Customer Search Configuration](/admin-and-rights/about/about-customer-search-configuration). If you want procedural information on creating and arranging search attributes, see [Create Customer Search Attributes](/admin-and-rights/create/create-customer-search-attributes).
- **_Customers2 Settings_**

  Customizing UI components for the Customers Module using the Customers 2 Settings page. To learn about this function, see [About Customers 2 Settings](/admin-and-rights/about/about-customers-2-settings). If you want information on performing specific tasks within this function, see [Configure Customers Module](/admin-and-rights/create/configure-customers-module).
