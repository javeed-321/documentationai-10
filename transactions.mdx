The Transactions API specification is published as an interactive Swagger reference, where you can browse every endpoint, inspect request and response schemas, and try calls against the platform.

<Card title="Open the Transactions API reference" href="https://domains-connecteast1.ent-sessionm.com/transactions/swagger/ui/index#/" icon="receipt" horizontal="false">
  APIs that handle transactions procedurally, storing items and payments. Endpoints are available that retrieve transaction information as single transactions or as pageable, sortable lists. The publishing feature can broadcast to accomplish point economy operations.
</Card>

<Callout kind="info">
  Before calling any endpoint, obtain your API key and S2S API secret. See [Before You Begin](/developer/before-you-begin).
</Callout>
