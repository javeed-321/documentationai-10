The **Scrut - Hunter** integration fetches user access data, permissions, and role assignments from your Hunter account and syncs them with the [Access Review](https://help.scrut.io/docs/what-is-access-review) module. This integration enables your organization to maintain comprehensive visibility over user access rights and streamline periodic access reviews for compliance and security.

<Callout kind="alert">
  Heads Up!

  The data synced from Hunter flows into the **People → Access** module in Scrut.
</Callout>

## Prerequisites

Before starting the integration, ensure you have the following credentials:

- You must be a Scrut Admin (or Contributor with access to the Integrations module)
- Hunter account with API access

**Note:** If you haven’t already created an API key, you’ll need to create one.

## How To Connect Hunter With Scrut

### Step 1: Fetch API Key from Hunter

1. Log in to your Hunter account and click **API** on the left navigation panel.
2. In the API page, you’ll see all your existing API keys, or you can create a new one by clicking the **+New key** button.
3. Copy the generated API Key and store it in a safe location. You must enter it in Scrut in the next step.

### Step 2: Go To Integrations in Scrut

1. [Sign in to Scrut](https://app.scrut.io/) and click **Integrations** on the left navigation panel.
2. Navigate to the **Integrations Library** tab, and choose **Miscellaneous** in the **Categories** section.
3. Scroll to the **Hunter** tile and click **Integrate**.

4. On the integration page, paste the **API Key** obtained in Step 1.
5. Click **Submit**.

## Synchronization Details

- **Initial Sync**: Upon completing the integration, Scrut will start syncing user data from Hunter. This process typically takes a few hours to complete. Check the Audit Log on the Hunter integration page in Scrut to review the status.
- **Recurring Sync**: After this, Scrut performs a sync **every 24 hours** to fetch incremental data, such as new users, role changes, and permission updates.
- **Manual Sync**: You can also click the **Sync Now** button to trigger an immediate data refresh.

## Data Fetched from Hunter

Scrut fetches the following access-related data points from Hunter:

- User Name
- User Email
- User Role

## Viewing Hunter Data in Scrut

To view the data fetched from your Hunter account, go to the **People → Access → Overview** tab. On this page, you can see the user details for your Hunter account.

You can also create an Access Review (or edit an existing one) and include the Hunter application in scope. Refer to this guide for step-by-step instructions on [creating an access review](https://help.scrut.io/docs/creating-a-new-access-review).

Follow these steps to create a new access review for Hunter:

1. Go to **People → Access** and click **Create New**.
2. Enter Review Details: Name, Description, Owner, and Review Days.
3. In step 2, search for and select Hunter in the Applications in Scope.
4. Select **Reviewer** and **Approver**.
5. Review the details and click **Save Review**.

From the Access Review page, click Hunter to view user details in Scrut.
