---
title: "Edit or Delete a Framework Requirement"
description: "Learn how to edit or delete framework requirements in Scrut."
---

<Callout kind="info">
  Who can use this feature

  - Supported on **Foundation, Growth,** and **Scale** plans
</Callout>

Scrut makes it easy to modify and remove requirements.

## Editing a Requirement

1. [Sign in to Scrut](https://app.scrut.io/) and go to **Compliance → Framework** using the left side panel.
2. Click the **My Frameworks** tab, and select the framework for which you want to modify a requirement.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786432263304-bc2w0aseyj-click-the-my-frameworks-tab-and-select-the-84694229.png?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="Click the My Frameworks tab, and select the framework for which you want to modify a requirement" caption=" " />
3. Click on the requirement page and then click the **three-dot icon** next to the requirement name.
4. Optionally, use the search bar at the top to find a specific requirement. You can search by requirement name, code, or category.
5. Click the three-dot icon <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786432302475-crxjzp6lqos-three-dots-icon-51c8d982.png?fm=auto&auto=compress%2Cformat" width="20" height="20" alt="Three-dots icon" caption=" " /> next to the requirement and choose **Edit Requirement**.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786429279779-ls22jh68ok9-editing-and-deleting-framework-requirement__03-click-the-three-dot-icon-next-to-the.png?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="Click the three-dot icon next to the requirement and choose Edit Requirement" caption=" " />
6. You can modify the following requirement details:
  - Category
  - Code
  - Name
  - Description
7. Click **Update Requirement**.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786429282032-4lnczdtirc-editing-and-deleting-framework-requirement__04-click-update-requirement.png?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="Click Update Requirement" caption=" " />
8. Watch out for the “Requirement updated successfully!” notification message.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786429284372-ukb3ifklhze-editing-and-deleting-framework-requirement__05-watch-out-for-the-requirement-updated.png?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="Watch out for the “Requirement updated successfully!” notification message" caption=" " />

## Deleting a Requirement

1. [Sign in to Scrut](https://app.scrut.io/) and go to **Compliance → Framework** using the left side panel.
2. Click the **My Frameworks** tab, and select the framework for which you want to delete a requirement.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786432263304-bc2w0aseyj-click-the-my-frameworks-tab-and-select-the-84694229.png?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="Click the My Frameworks tab, and select the framework for which you want to delete a requirement" caption=" " />
3. Click on the requirement category and click the **three-dot icon** next to the requirement name you want to delete.

<Callout kind="danger">
  Heads Up!

  You cannot delete a mandatory requirement.
</Callout>
4. Click the three-dot icon <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786432302475-crxjzp6lqos-three-dots-icon-51c8d982.png?fm=auto&auto=compress%2Cformat" width="20" height="20" alt="Three-dots icon" caption=" " /> next to the requirement and choose **Delete Requirement**.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786429287354-1wt1h55p3k6-editing-and-deleting-framework-requirement__08-click-the-three-dot-icon-next-to-the.png?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="Click the three-dot icon next to the requirement and choose Delete Requirement" caption=" " />
5. A confirmation window appears. Click **Delete**.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786429289941-jugwfi0kpxr-editing-and-deleting-framework-requirement__09-a-confirmation-window-appears-click-delete.png?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="A confirmation window appears. Click Delete" caption=" " />

<Callout kind="danger">
  Warning

  Deleting a requirement is permanent. So, proceed with caution.
</Callout>
