The **Scrut-Stripe** integration fetches user access data, permissions, and role assignments from your Stripe account and sends the data to the [Access Review](https://help.scrut.io/docs/what-is-access-review) module in Scrut. This integration enables your organization to maintain comprehensive visibility over user access rights and streamline periodic access reviews for compliance and security.

<Callout kind="alert">
  Heads Up!

  The data synced from Stripe flows into the **Access Review** module in Scrut.
</Callout>

## How To Connect Stripe With Scrut

## Prerequisites

Before starting the integration, ensure you have the following access and permissions:

### Access

- You must be a Scrut Admin (or Contributor with access to the Integrations module)
- You must have permissions to generate an API key in Stripe

### Permissions

Scrut requires **read-only access** to the following data in Stripe

- User Accounts: View name, email, and user role

<Callout kind="info">
  Pro Tip!

  We recommend logging into your Stripe account before starting the integration to avoid doing so later.
</Callout>

### Step 2: Navigate to Integrations in Scrut

1. Sign in to your Scrut account and click **Integrations** on the left navigation panel.
2. Go to the **Integrations Library** tab, and in the **Categories** section, click **Miscellaneous**.
3. Locate the Stripe tile and click **Integrate**.

## Synchronization Details

- **Initial Sync**: Upon completing the integration, Scrut will immediately sync user data from Stripe.
- **Recurring Sync**: After this, Scrut performs the sync **every 24 hours** to fetch incremental data.

## Data Fetched from Stripe

Scrut fetches the following access-related data points from Stripe:

- User Name
- User Email
- User Role

## Viewing Stripe Data in Scrut

To view the data fetched from your Stripe account, you’ll need to create an Access Review (or edit an existing one) and include the Stripe application in scope. Refer to this guide for step-by-step instructions on [creating an access review](https://help.scrut.io/docs/creating-a-new-access-review).
