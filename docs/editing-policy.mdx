2. Go to the **All Policies** tab and select your preferred policy.

## Editing Details of a Single Policy

1. Sign in to Scrut, and click **Compliance → Policies** on the left navigation panel.
2. Go to the **All Policies** tab and select your preferred policy.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786432273954-7hzl3vl7nzj-go-to-the-all-policies-tab-and-select-your-9046bb29.png?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="Go to the All Policies tab and select your preferred policy" caption=" " />
3. This brings you to the Policy Details page.
4. You can edit policy details, such as:

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786431895387-d6z3isl2g5f-editing-policy__06-you-can-edit-policy-details-such-as.png?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="You can edit policy details, such as" caption=" " />
  - **Requirement:** Edit or modify policy requirements.
  - **Assigned To:** Choose one or more assignees for the policy and click **Make Primary** to designate a Primary Assignee.
  - **Approvers:** You can add up to five approvers for a policy. Drag and drop approvers to arrange them in hierarchical order. You can update approvers only for policies that aren’t in the Published state.
  - **Entities:** Link the policy to the desired entities.
  - **Effort Estimate:** Select the estimated effort to implement this policy. You can choose from Low, Medium, or High.
  - **Department:** Modify the department for the policy.
  - **Recurrence:** Set the policy recurrence schedule: Annually, Biannually, Quarterly, Monthly, or Never.
  - **Next Review Date:** Set the next review date for the selected policies. This option is only available for policies in the **Published** or **Needs Review** status.

## Editing Policy Details in Bulk

Scrut also gives you the flexibility to edit the details of multiple policies simultaneously:

1. Go to the **All Policies** tab and select the policies that you want to edit.
2. Click the **Edit** button at the top of the Policy table.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786431897134-8r38iqs48bs-editing-policy__07-click-the-edit-button-at-the-top-of-the.png?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="Click the Edit button at the top of the Policy table" caption=" " />
3. This opens the Edit details drawer. You can edit the following fields:
  - **Assignees:** Choose one or more assignees for the policies and click **Make Primary** to designate a Primary Assignee.
  - **Approvers**: You can add up to five approvers for a policy. Drag and drop approvers to arrange them in hierarchical order. You can update approvers only for policies that aren’t in the Published state.
  - **Entities:** Link the selected policies to the desired entities.
  - **Effort Estimate:** Select the estimated effort to implement this policy. You can choose from Low, Medium, or High.
  - **Recurrence:** Set the policy recurrence schedule: Annually, Biannually, Quarterly, Monthly, or Never.
  - **Department:** Modify the departments for selected policies in one go.
  - **Next Review Date:** Set the next review date for the selected policies. This option is only available for policies in the **Published** or **Needs Review** status.
  - **Relevance:** Mark all selected policies as relevant or not relevant.
4. Click **Save**. The changes will be applied to all selected policies.

<Callout kind="alert">
  Note:

  If you wish to retain the existing values for a field, simply leave it unchanged. Scrut will only update the fields you've modified in this window, ensuring that the other values remain intact.
</Callout>
