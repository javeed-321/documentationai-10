The **Scrut-greytHR integration** fetches employee data from your greytHR account and sends it to Scrut. Upon completing the integration, Scrut will display the fetched data in:

- [People module](https://help.scrut.io/docs/employees-1)

## Prerequisites

Before starting the integration, ensure you have the following permissions for your greytHR account:

- **Account Information**: Login credentials
- **Access Level**: Admin access to greytHR
- **Permissions**: Scrut requires read access to the following data:
  - Read: user_profile
  - Read: employment_info
  - Read: manager_info (wherever applicable)
  - Read: leave_data

<Callout kind="info">
  Pro Tip:

  We recommend logging into your greytHR account before starting the integration to avoid doing so later.
</Callout>

## How To Integrate Scrut With greytHR

### Step 1: Generate greytHR API Credentials

1. Log in to your greytHR account and navigate to **Settings** → **My Account → API Users**.
2. On the API Users page, click **Create API User**.
3. In the **Add API User** pop-up, enter the **User Name**, like Scrut Automation.
4. [Optional] In the **Description** text box, you can enter a short description, such as “Integration to connect with Scrut Automation.”
5. In the **Select Roles** section, you can select the roles of the API user. You can select multiple roles.
6. Click **Next**.
7. A pop-up appears with the **User Name** and **Password** for the created API user.

<Callout kind="alert">
  Heads Up!

  - Make sure to save this information as it’s crucial for integrating with Scrut. Copy and paste the API User Name and Key in a safe location. You’ll need to enter it in Scrut in [Step 2](/docs/integrating-greythr#step-2-connect-your-greythr-account-in-scrut).
  - For detailed instructions, refer to [greytHR’s documentation](https://admin-help.greythr.com/admin/answers/123842254).
</Callout>

### Step 2: Connect Your greytHR Account in Scrut

1. Sign in to your Scrut account and click **Integrations** on the left navigation panel.
2. Navigate to the **Integrations Library** tab and select **Human Resource Information Systems** from the Categories section.
3. Scroll to the greytHR tile and click **Integrate**.

4. On the greytHR integrations page, click the **Connect** button on the top right.

6. Copy and paste the **greytHR API Username** and **API Key** that you generated in [Step 1](/docs/integrating-greythr#step-1-generate-greythr-api-credentials).

## Synchronization Details

- **Initial Sync**: Upon completing the integration, Scrut will immediately sync employee data from your greytHR account.
- **Recurring Sync**: After this, Scrut performs the sync **every 24 hours** to fetch incremental data.
- **Manual Sync:** You can also initiate a manual sync by clicking the **Sync Now** button on the greytHR integrations page.

## Data Fetched from greytHR

Scrut fetches the following data for all your employees from greytHR:

- Employee name
- Email address
- Joining date
- Exit date (if applicable)
- Department and Role (if available)
- Email of reporting manager (if available)
- Leave data (start date, end date, and status)

## Viewing greytHR Data in Scrut

To view greytHR data in Scrut:

1. Go to **People → Employees → All Employees**.
2. Click on any employee to view their details, including name, email, joining date, reporting manager, and more.
