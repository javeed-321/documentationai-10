The **Scrut - Less Annoying CRM** integration fetches user access data, permissions, and role assignments from your Less Annoying CRM account and syncs them with the [Access Review](https://help.scrut.io/docs/what-is-access-review) module. This integration enables your organization to maintain comprehensive visibility over user access rights and streamline periodic access reviews for compliance and security.

<Callout kind="alert">
  Heads Up!

  The data synced from Less Annoying CRM flows into the **People → Access** module in Scrut.
</Callout>

## Prerequisites

Before starting the integration, ensure you have the following credentials:

- You must be a Scrut Admin (or Contributor with access to the Integrations module)
- Less Annoying CRM account with API access enabled

**Note:** If you haven’t already created an API key, you’ll need to create one.

## How To Connect Less Annoying CRM With Scrut

### Step 1: Fetch API Key from Less Annoying CRM

1. Log in to your Less Annoying CRM account and click **Settings** on the left panel.
2. Navigate to **Other Tools → Programmer API**.
3. Click **Enable API** if accessing for the first time.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786430780885-c7cgetmuiao-integrating-less-annoying-crm__01-click-enable-api-if-accessing-for-the-first.png?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="Click Enable API if accessing for the first time" caption=" " />
4. Click **Create a new API Key** button.
5. Enter a **Name** for the key, such as Scrut Integration.
6. In **Permissions**, select **Read access** (view data already in the CRM)
7. Click **Create key** to generate your API key.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786430782850-4yrkcvtvt73-integrating-less-annoying-crm__02-click-create-key-to-generate-your-api-key.png?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="Click Create key to generate your API key" caption=" " />
8. Copy the generated API key and store it in a safe location.

**Note:** The API key is displayed only once. Less Annoying CRM encrypts the API key at rest, so you cannot retrieve it later. If you lose it, you’ll need to create a new one and reconfigure the Scrut integration.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786430784471-fbcfc4frixc-integrating-less-annoying-crm__03-note-the-api-key-is-displayed-only-once.png?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="Note: The API key is displayed only once" caption=" " />

### Step 2: Go To Integrations in Scrut

1. [Sign in to Scrut](https://app.scrut.io/) and click **Integrations** on the left navigation panel.
2. Navigate to the **Integrations Library** tab, and choose **Customer Relationship Management** in the **Categories** section.
3. Scroll to the **Less Annoying CRM** tile and click **Integrate**.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786430786211-rc7e5gmckfo-integrating-less-annoying-crm__04-scroll-to-the-less-annoying-crm-tile-and.png?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="Scroll to the Less Annoying CRM tile and click Integrate" caption=" " />
4. On the integration page, paste the **API Key** obtained in Step 1.
5. Click **Submit**.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786430788041-m9jrvvmlss-integrating-less-annoying-crm__05-click-submit.png?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="Click Submit" caption=" " />
6. Once authorization is done, you’ll see the success toast and the **Connected** status indicator.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786430789871-3kmko6wobll-integrating-less-annoying-crm__06-once-authorization-is-done-youll-see-the.png?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="Once authorization is done, you’ll see the success toast and the Connected status indicator" caption=" " />

## Synchronization Details

- **Initial Sync**: Upon completing the integration, Scrut will start syncing user data from Less Annoying CRM. This process typically takes a few hours to complete. Check the Audit Log on the Less Annoying CRM integration page in Scrut to review the status.
- **Recurring Sync**: After this, Scrut performs a sync **every 24 hours** to fetch incremental data, such as new users, role changes, and permission updates.
- **Manual Sync**: You can also click the **Sync Now** button to trigger an immediate data refresh.

## Data Fetched from Less Annoying CRM

Scrut fetches the following access-related data points from Less Annoying CRM:

- User Name
- User Email
- User Role

## Viewing Less Annoying CRM Data in Scrut

To view the data fetched from your Less Annoying CRM account, go to the **People → Access → Overview** tab. On this page, you can see the user details for your Less Annoying CRM account.

You can also create an Access Review (or edit an existing one) and include the Less Annoying CRM application in scope. Refer to this guide for step-by-step instructions on [creating an access review](https://help.scrut.io/docs/creating-a-new-access-review).

Follow these steps to create a new access review for Less Annoying CRM:

1. Go to **People → Access** and click **Create New**.
2. Enter Review Details: Name, Description, Owner, and Review Days.
3. In step 2, search for and select Less Annoying CRM in the Applications in Scope.
4. Select **Reviewer** and **Approver**.
5. Review the details and click **Save Review**.

From the Access Review page, click Less Annoying CRM to view user details in Scrut.
