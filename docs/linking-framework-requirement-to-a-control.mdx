title: "Link and Unlink Controls to a Framework Requirement"

---

<Callout kind="info">
  Who can use this feature

  - Supported on **Foundation, Growth,** and **Scale** plans
</Callout>

Requirements of standard frameworks like ISO, SOC2, GDPR, and others are already linked to controls. These mappings are pre-established by Scrut. However, if you have created a custom framework requirement, Scrut provides you with the flexibility to link and unlink controls, as needed.

## Linking Controls to a Requirement

To link one or more controls to a requirement, follow the steps outlined below:

1. Sign in to Scrut, and go to **Compliance → Frameworks** using the left navigation panel.
2. Click on the framework to which you want to link a control.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786429442947-xkfi1v7re5-linking-framework-requirement-to-a-control__01-click-on-the-framework-to-which-you-want-to.png?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="Click on the framework to which you want to link a control" caption=" " />
3. Locate the specific requirement to which you want to link a control.
4. To narrow down your options, use the search bar at the top. You can search by Requirement Name, Code, or Category.
5. If needed, apply the **Scope** filter at the top to view requirements categorized as In Scope or Out of Scope.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786429445157-y8b5yl1ftbr-linking-framework-requirement-to-a-control__02-if-needed-apply-the-scope-filter-at-the-top.png?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="If needed, apply the Scope filter at the top to view requirements categorized as In Scope or Out of Scope" caption=" " />
6. Expand the requirement to view its details in a side drawer.
7. Click the **Link / Unlink Controls** button.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786429447430-7ydlfodfo88-linking-framework-requirement-to-a-control__03-click-the-link-unlink-controls-button.png?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="Click the Link / Unlink Controls button" caption=" " />
8. In the Link / Unlink Controls window, select the checkboxes for the control(s) you want to link.
9. Optionally, use the search bar to find specific controls by name or code.
10. If needed, use the Domain, Frameworks, and Entities filters at the top to filter specific controls.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786429449561-7vcokwyf1o7-linking-framework-requirement-to-a-control__04-if-needed-use-the-domain-frameworks-and.png?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="If needed, use the Domain, Frameworks, and Entities filters at the top to filter specific controls" caption=" " />
11. Once you've selected the desired controls, enable the **Show Linked Controls** toggle to review and verify your selection.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786429451702-4kdei5stay-linking-framework-requirement-to-a-control__05-once-youve-selected-the-desired-controls.png?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="Once you've selected the desired controls, enable the Show Linked Controls toggle to review and verify your" caption=" " />
12. Click **Save** to complete the process.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786429454078-7jtijxfogig-linking-framework-requirement-to-a-control__06-click-save-to-complete-the-process.png?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="Click Save to complete the process" caption=" " />

## Unlinking Controls to a Requirement

1. Locate the specific requirement from which you want to unlink a control.
2. Expand the requirement to view its details in a side drawer.
3. Click the **Link / Unlink Controls** button.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786429456431-3dxxnoiq0ni-linking-framework-requirement-to-a-control__07-click-the-link-unlink-controls-button.png?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="Click the Link / Unlink Controls button" caption=" " />
4. In the Link / Unlink Controls window, **deselect the checkboxes** for the control(s) you want to unlink.
5. Click **Save** to complete the process.
