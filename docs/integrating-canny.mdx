The **Scrut - Canny** integration fetches user access data, permissions, and role assignments from your Canny account and syncs them with the [Access Review](https://help.scrut.io/docs/what-is-access-review) module. This integration enables your organization to maintain comprehensive visibility over user access rights and streamline periodic access reviews for compliance and security.

<Callout kind="alert">
  Heads Up!

  The data synced from Canny flows into the **People → Access** module in Scrut.
</Callout>

## Prerequisites

Before starting the integration, ensure you have the following credentials:

- You must be a Scrut Admin (or Contributor with access to the Integrations module)
- You have permissions to view your organization’s Secret API Key in Canny.

<Callout kind="info">
  Pro Tip!

  We recommend logging into your Canny account before starting the integration to avoid doing so later.
</Callout>

## How To Connect Canny With Scrut

### Step 1: Copy Secret API Key from Canny

1. Log in to your Canny account, click your profile and go to **Settings**.
2. Click **API** in the left navigation menu, then copy your **Secret API Key**.
3. You’ll need to enter it in Scrut in the [next step](/v1/docs/integrating-canny#step-2-go-to-integrations-in-scrut).

**Note:** Refer to this guide from Canny for [more information on the API key](https://developers.canny.io/api-reference).

### Step 2: Go To Integrations in Scrut

1. [Sign in to Scrut](https://app.scrut.io/) and click **Integrations** on the left navigation panel.
2. Navigate to the **Integrations Library** tab, and choose **Project Management Tools** in the **Categories** section.
3. Scroll to the **Canny** tile and click **Integrate**.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786430246353-gl3rckl1jei-integrating-canny__02-scroll-to-the-canny-tile-and-click-integrate.png?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="Scroll to the Canny tile and click Integrate" caption=" " />
4. On the integration page, paste the API key obtained in [Step 1](/v1/docs/integrating-canny#step-1-copy-secret-api-key-from-canny).
5. Click **Submit**.

## Synchronization Details

- **Initial Sync**: Upon completing the integration, Scrut will start syncing user data from Canny. This process typically takes a few hours to complete. Check the Audit Log on the Canny integration page in Scrut to review the status.
- **Recurring Sync**: After this, Scrut performs the sync once **every 24 hours** to fetch incremental data such as new users, role changes, and permission updates.
- **Manual Sync**: You can also click the **Sync Now** button to trigger an immediate data refresh.

## Data Fetched from Canny

Scrut fetches the following access-related data points from Canny:

- User Name
- User Email
- User Role

## Viewing Canny Data in Scrut

To view the data fetched from your Canny account, go to the **People → Access → Overview** tab. On this page, you can see the user details for your Canny account.

You can also create an Access Review (or edit an existing one) and include the Canny application in scope. Refer to this guide for step-by-step instructions on [creating an access review](https://help.scrut.io/docs/creating-a-new-access-review).

Follow these steps to create a new access review for Canny:

1. Go to **People → Access** and click **Create New**.
2. Enter Review Details: Name, Description, Owner, and Review Days.
3. In step 2, search for and select Canny in the Applications in Scope.
4. Select **Reviewer** and **Approver**.
5. Review the details and click **Save Review**.

From the Access Review page, click Canny to view user details in Scrut.
