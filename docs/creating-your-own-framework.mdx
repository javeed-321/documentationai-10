Scrut provides a growing library of [ready-to-use frameworks](/docs/framework-overview) for various regulatory and industry standards. If, however, you have a set of requirements not covered in the library (such as an internal compliance program, a program you run for your customers or vendors, or just a differently structured compliance standard), you can create a custom framework for your organization.

## How To Create a Custom Framework

1. Sign in to Scrut, and click Compliance → Framework on the left navigation panel.
2. Click +**Create Framework**.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786429197311-gd5pcex184-creating-your-own-framework__01-click-create-framework.png?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="Click +Create Framework" caption=" " />

3. In the Framework Name field, enter a name for the framework.
4. From the Entity section, select an entity to which you would like to link your framework.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786429199412-68815egbeuc-creating-your-own-framework__02-from-the-entity-section-select-an-entity-to.png?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="From the Entity section, select an entity to which you would like to link your framework" caption=" " />
5. On clicking **Create**, Scrut will create the custom framework and add it to the My Frameworks tab.
