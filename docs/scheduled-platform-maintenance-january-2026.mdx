## System Upgrades

Our technical team will be implementing the following improvements during the downtime:

### SSL Certificate Transition (SAN to SNI)

Scrut is upgrading how we manage SSL certificates for trust vault domains, transitioning to an SNI (Server Name Indication)–based mechanism. This change is necessary to improve scalability and ensure the long-term reliability and security of certificate management.

SNI allows multiple SSL certificates to be hosted on a single IP address, enabling better resource utilization and enhanced security protocols. This upgrade will provide a more robust and future-proof infrastructure for managing secure connections across the Scrut platform.

### Database Optimization (PostgreSQL Reclustering) - Deferred

We have decided to defer the PostgreSQL database reclustering to a later maintenance window. We will perform a re-clustering of our PostgreSQL databases to significantly improve overall query performance and responsiveness for all users. This optimization will:

- Reduce query execution times across the platform
- Enhance system responsiveness during peak usage
- Improve data retrieval efficiency for compliance reports and dashboards
- Provide a more stable foundation for future feature enhancements

The re-clustering process reorganizes database structures to eliminate fragmentation and optimize data access patterns, resulting in faster load times and a smoother user experience across the platform.
