The **Scrut - NetSuite** integration fetches user access data, permissions, and role assignments from your NetSuite account and syncs them with the [Access Review](https://help.scrut.io/docs/what-is-access-review) module. This integration enables your organization to maintain comprehensive visibility over user access rights and streamline periodic access reviews for compliance and security.

<Callout kind="alert">
  Heads Up!

  The data synced from NetSuite flows into the **Access Review** module in Scrut.
</Callout>

## Prerequisites

Before starting the integration, ensure you have the following access and permissions:

### Access

- You must be a Scrut Admin (or Contributor with access to the Integrations module)
- NetSuite account with REST Web Services enabled
  - To enable REST Web Services, navigate to **Setup → Company → Enable Features** and select the **REST Web Services checkbox** in the **SuiteCloud** tab
- [Token-based Auth enabled](/docs/integrating-netsuite#step-1-enable-tokenbased-auth-in-your-netsuite-account) in your organization’s NetSuite account
- You must be a NetSuite admin to fetch the Consumer Key, Consumer Secret, Token ID, and Token Secret

### Permissions

Scrut requires **read-only access** to the following data in NetSuite

- User Accounts: View name, email, and user role

<Callout kind="info">
  Pro Tip!

  We recommend logging into your NetSuite account before starting the integration to avoid doing so later.
</Callout>

## How To Connect NetSuite With Scrut

### Step 1: Enable Token-Based Auth in Your NetSuite Account

1. Navigate to **Setup → Company → Enable Features** in your NetSuite account.
2. Select the **SuiteCloud** tab, scroll down and select the **Token-Based Authentication** checkbox under the **Manage Authentication** section.

### Step 2: Fetch the Required Credentials from NetSuite

For this integration, you need to fetch the following details from NetSuite:

1. Account ID
2. Consumer Key
3. Consumer Secret
4. Token ID
5. Token Secret

In this section, we explain how to fetch these required credentials:

1. Log in to your NetSuite account with admin permissions.
2. Navigate to **Setup → Company → Company Information** and copy the **Account ID** from there. Save it in a safe location as you’ll need to enter it in Scrut in the next step.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786430877765-r0db4zahye9-integrating-netsuite__02-navigating-for-account-id.png?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="Navigating for Account ID" caption=" " />
3. Click **Setup → Integration → Manage Integrations** and choose **New**.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786430879368-q8vwptiayn-integrating-netsuite__03-navigating-for-app-creation.png?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="Navigating for App creation" caption=" " />
4. Enter an app name, such as Scrut Integration. Under **Authentication → Token-based Authentication**, **uncheck** the **TBA: Authorization Flow** checkbox. **Uncheck** the **Authorization Code Grant** checkbox under **OAuth 2.0**.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786430881019-76op6pjz4ms-integrating-netsuite__04-creating-integration-credentials.png?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="Creating Integration Credentials" caption=" " />
5. Click **Save** and copy the **Consumer Key** and **Consumer Secret** displayed in the **Client Credentials** section. Save it in a safe location, as you’ll need to enter these details in Scrut in the next step.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786430882641-wkum2ory2s-integrating-netsuite__05-getting-consumer-key-and-secret.png?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="Getting Consumer Key and Secret" caption=" " />
6. Navigate to **Setup → Users/Roles → Access Tokens** and click **New**.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786430884208-98shd7b1olo-integrating-netsuite__06-navigation-for-token-credentials.png?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="Navigation for Token Credentials" caption=" " />
7. Click **New My Access Token**, and select the integration created above from the **Application Name** dropdown. Enter a **Token Name** and click **Save**.

<Callout kind="danger">
  Important:

  Make sure you select the correct app in the Application name dropdown.
</Callout>
8. Copy the **Token ID** and **Token Secret** displayed in the Token ID/Secret section. Save it in a safe location, as you’ll need to enter these details in Scrut in the next step.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786430943510-yx07x3f6fw-integrating-netsuite__07-getting-token-id-and-secret.png?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="Getting Token ID and Secret" caption=" " />

You now have all the details required for the Scrut integration.

<Callout kind="info">
  Pro Tip!

  Refer to this guide from NetSuite for [more information on token-based authentication](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161942084079.html).
</Callout>

### Step 2: Go To Integrations in Scrut

1. [Sign in to Scrut](https://app.scrut.io/) and click **Integrations** on the left navigation panel.
2. Navigate to the **Integrations Library** tab, and choose **Customer Relationship Management** in the **Categories** section.
3. Scroll to the **NetSuite** tile and click **Integrate**.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786430946698-phufuo8fpn-integrating-netsuite__08-scroll-to-the-netsuite-tile-and-click.png?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="Scroll to the NetSuite tile and click Integrate" caption=" " />
4. On the integration page, paste the credentials obtained in [Step 2](/docs/integrating-netsuite#step-2-fetch-the-required-credentials-from-netsuite).
5. Click **Submit**.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786430948427-cw7oaf0q859-integrating-netsuite__09-click-submit.png?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="Click Submit" caption=" " />
6. Once authorization is done, you’ll see the “**Connected Successfully**” message and the **Connected** status indicator.

## Synchronization Details

- **Initial Sync**: Upon completing the integration, Scrut will start syncing user data from NetSuite. This process typically takes a few hours to complete. Check the Audit Log on the NetSuite integration page in Scrut to review the status.
- **Recurring Sync**: After this, Scrut performs the sync once **every 24 hours** to fetch incremental data such as new users, role changes, and permission updates.
- **Manual Sync**: You can also click the **Sync Now** button to trigger an immediate data refresh.

## Data Fetched from NetSuite

Scrut fetches the following access-related data points from NetSuite:

- User Name
- User Email
- User Role

## Viewing NetSuite Data in Scrut

To view the data fetched from your NetSuite account, go to the **People → Access → Overview** tab. On this page, you can see the user details for your NetSuite account.

You can also create an Access Review (or edit an existing one) and include the NetSuite application in scope. Refer to this guide for step-by-step instructions on [creating an access review](https://help.scrut.io/docs/creating-a-new-access-review).

Follow these steps to create a new access review for NetSuite:

1. Go to **People → Access** and click **Create New**.
2. Enter Review Details: Name, Description, Owner, and Review Days.
3. In step 2, search for and select NetSuite in the Applications in Scope.
4. Select **Reviewer** and **Approver**.
5. Review the details and click **Save Review**.

From the Access Review page, click NetSuite to view user details in Scrut.
