The **Scrut-Aircall** integration fetches user access data, permissions, and role assignments from your Aircall account and sends the data to the [Access Review](https://help.scrut.io/docs/what-is-access-review) module in Scrut. This integration enables your organization to maintain comprehensive visibility over user access rights and streamline periodic access reviews for compliance and security.

<Callout kind="alert">
  Heads Up!

  The data synced from Aircall flows into the **Access Review** module in Scrut.
</Callout>

## How To Connect Aircall With Scrut

## Prerequisites

Before starting the integration, ensure you have the following access and permissions:

### Access

- You must be a Scrut Admin (or Contributor with access to the Integrations module)
- You must have permissions to fetch the API ID and Token in Aircall

### Permissions

Scrut requires **read-only access** to the following data in Aircall

- User Accounts: View name, email, and user role

<Callout kind="info">
  Pro Tip!

  We recommend logging into your Aircall account before starting the integration to avoid doing so later.
</Callout>

### Step 1: Fetch the API Key from Your Aircall Account

1. Log in to your Aircall account.
2. Click **Integrations & API** in the left-side navigation menu, and then click **API Keys**.
3. Click **Generate an API key**.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786429962701-c4l69a6ccdl-integrating-aircall__01-click-generate-an-api-key.png?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="Click Generate an API key" caption=" " />
4. Enter the key name (such as Scrut Integration).
5. Copy the **API ID** and **API Token** displayed on the screen. Save them in a safe location as they won’t be shown again.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786429964354-vc880epw0af-integrating-aircall__02-copy-the-api-id-and-api-token-displayed-on.png?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="Copy the API ID and API Token displayed on the screen" caption=" " />

### Step 2: Navigate to Integrations in Scrut

1. Sign in to your Scrut account and click **Integrations** on the left navigation panel.
2. Go to the **Integrations Library** tab, and in the **Categories** section, click **Miscellaneous**.
3. Locate the **Aircall** tile and click **Integrate**.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786429966124-hrzn315chsj-integrating-aircall__03-locate-the-aircall-tile-and-click-integrate.png?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="Locate the Aircall tile and click Integrate" caption=" " />
4. On the Aircall integration page, enter the **API ID** and **API Token** you copied in the previous step and click **Submit**.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786429967998-3fjucc3owdr-integrating-aircall__04-on-the-aircall-integration-page-enter-the.png?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="On the Aircall integration page, enter the API ID and API Token you copied in the previous step and click" caption=" " />
5. Watch for the **Connected Successfully** notification message and the **Connected** status indicator.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786429969996-en1u0l5um4r-integrating-aircall__05-watch-for-the-connected-successfully.png?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="Watch for the Connected Successfully notification message and the Connected status indicator" caption=" " />

## Synchronization Details

- **Initial Sync**: Upon completing the integration, Scrut will immediately start syncing user data from Aircall. Check the Audit Log to view sync status.
- **Recurring Sync**: After this, Scrut performs the sync **every 24 hours** to fetch incremental data.
- **Manual Sync**: You can also click the **Sync Now** button to trigger an immediate data refresh.

## Data Fetched from Aircall

Scrut fetches the following access-related data points from Aircall:

- User Name
- User Email
- User Role

## Viewing Aircall Data in Scrut

To view the data fetched from your Aircall account, you’ll need to create an Access Review (or edit an existing one) and include the Aircall application in scope. Refer to this guide for step-by-step instructions on [creating an access review](https://help.scrut.io/docs/creating-a-new-access-review).
