The **Scrut - ActiveCampaign** integration fetches user access data, permissions, and role assignments from your ActiveCampaign account and syncs them with the [Access Review](https://help.scrut.io/docs/what-is-access-review) module. This integration enables your organization to maintain comprehensive visibility over user access rights and streamline periodic access reviews for compliance and security.

<Callout kind="alert">
  Heads Up!

  The data synced from ActiveCampaign flows into the **People → Access** module in Scrut.
</Callout>

## Prerequisites

Before starting the integration, ensure you have the following credentials:

- You must be a Scrut Admin (or Contributor with access to the Integrations module)
- You must have permissions to fetch the API key and URL in ActiveCampaign

<Callout kind="info">
  Pro Tip!

  We recommend logging into your ActiveCampaign account before starting the integration to avoid doing so later.
</Callout>

### Step 2: Go To Integrations in Scrut

1. [Sign in to Scrut](https://app.scrut.io/) and click **Integrations** on the left navigation panel.
2. Navigate to the **Integrations Library** tab, and choose **Customer Relationship Management** in the **Categories** section.
3. Scroll to the **ActiveCampaign** tile and click **Integrate**.

## Synchronization Details

- **Initial Sync**: Upon completing the integration, Scrut will start syncing user data from ActiveCampaign. This process typically takes a few hours to complete. Check the Audit Log on the ActiveCampaign integration page in Scrut to review the status.
- **Recurring Sync**: After this, Scrut performs the sync once **every 24 hours** to fetch incremental data such as new users, role changes, and permission updates.
- **Manual Sync**: You can also click the **Sync Now** button to trigger an immediate data refresh.

## Data Fetched from ActiveCampaign

Scrut fetches the following access-related data points from ActiveCampaign:

- User Name
- User Email
- User Role

## Viewing ActiveCampaign Data in Scrut

To view the data fetched from your ActiveCampaign account, go to the **People → Access → Overview** tab. On this page, you can see the user details for your ActiveCampaign account.

You can also create an Access Review (or edit an existing one) and include the ActiveCampaign application in scope. Refer to this guide for step-by-step instructions on [creating an access review](https://help.scrut.io/docs/creating-a-new-access-review).

Follow these steps to create a new access review for ActiveCampaign:

1. Go to **People → Access** and click **Create New**.
2. Enter Review Details: Name, Description, Owner, and Review Days.
3. In step 2, search for and select ActiveCampaign in the Applications in Scope.
4. Select **Reviewer** and **Approver**.
5. Review the details and click **Save Review**.

From the Access Review page, click ActiveCampaign to view user details in Scrut.
