The **Scrut - Hive** integration fetches user access data, permissions, and role assignments from your Hive account and sends them to Scrut’s Access Review module. This integration enables your organization to maintain comprehensive visibility over user access rights and streamline periodic access reviews for compliance and security.

<Callout kind="alert">
  Heads Up!

  The data synced from Hive flows into the **Access Review** module in Scrut.
</Callout>

## Prerequisites

Before starting the integration, ensure you have the following access and permissions:

### Access

- You must be a Scrut Admin (or Contributor with access to the Integrations module)
- You must have permissions to generate an API key in Hive

### Permissions

Scrut requires **read-only access** to the following data in Hive

- User Accounts: View name, email, and user role

<Callout kind="info">
  Pro Tip!

  We recommend logging into your Hive account before starting the integration to avoid doing so later.
</Callout>

## How To Connect Hive With Scrut

### Step 1: Fetch API Key and User ID from Hive

1. Log in to your Hive account, click your username on the top right and click **Edit Profile**.

2. Click **API info** on the left navigation menu.
3. Copy the **API key** and **User ID** and save them in a safe location, as you’ll need to enter them in Scrut in the [next step](/docs/integrating-hive#step-2-go-to-integrations-in-scrut).

**Note:** Refer to this guide from Hive for [more information on the API key](https://help.hive.com/en/articles/5407965-getting-started-with-the-hive-api).

### Step 2: Go To Integrations in Scrut

1. [Sign in to Scrut](https://app.scrut.io/) and click **Integrations** on the left navigation panel.
2. Navigate to the **Integrations Library** tab, and choose **Project Management Platforms** in the **Categories** section.
3. Scroll to the **Hive** tile and click **Integrate**.

5. Click **Submit**.

## Synchronization Details

- **Initial Sync**: Upon completing the integration, Scrut will start syncing user data from Hive. This process typically takes a few hours to complete. Check the Audit Log on the Hive integration page in Scrut to review the status.
- **Recurring Sync**: After this, Scrut performs the sync once **every 24 hours** to fetch incremental data such as new users, role changes, and permission updates.
- **Manual Sync**: You can also click the **Sync Now** button to trigger an immediate data refresh.

## Data Fetched from Hive

Scrut fetches the following access-related data points from Hive:

- User Name
- User Email
- User Role

## Viewing Hive Data in Scrut

To view the data fetched from your Hive account, you’ll need to create an Access Review (or edit an existing one) and include the Hive application in scope. Refer to this guide for step-by-step instructions on [creating an access review](https://help.scrut.io/docs/creating-a-new-access-review).

Follow these steps to create a new access review for Hive:

1. Go to **People → Access Review** and click **Create New**.
2. Enter Review Details: Name, Description, Owner, and Review Days.
3. In step 2, search for and select Hive in the Applications in Scope.
4. Select **Reviewer** and **Approver**.
5. Review the details and click **Save Review**.

From the Access Review page, click Hive to view user details in Scrut.
