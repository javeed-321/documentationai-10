---
title: "Understand Task Management Integration Capabilities"
description: "See which task management integrations support bidirectional sync and attachment imports for evidence tasks."
---

Integrating with a project management platform lets you create compliance-related tickets directly from Scrut in your connected tool. All integrations with the **Task Management** tag **support creating a ticket in Scrut and automatically syncing it to your connected tool**.

Some integrations also support additional capabilities, such as:

- **Bidirectional Status Sync:** Status changes made to linked tickets in your connected tool are automatically reflected in Scrut. This keeps compliance records in sync on both platforms, which is especially valuable when tracking remediation progress during audits.
- **Ticket Automation:** This feature enables Scrut to automatically create a new ticket each time a linked artifact moves to a non-compliant status:
  - Policy status changes to **Needs Review**
  - Evidence Task status changes to **Needs Attention**
  - Test status changes to **Fix Required**

  This keeps your team's task queue up to date without any manual effort.
- **Attachments for Evidence Tasks:** Files attached to a linked ticket in your connected tool are automatically imported into the corresponding evidence task in Scrut. For example, a screenshot or configuration export attached to a Jira ticket will sync automatically to the linked evidence task in Scrut.

**Note:** Applies only to tickets linked to an evidence task in Scrut. Attachments from unlinked tickets are not imported.
