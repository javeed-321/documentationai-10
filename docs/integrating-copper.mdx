The **Scrut - Copper CRM** integration fetches user access data, permissions, and role assignments from your Copper account and syncs them with the [Access Review](https://help.scrut.io/docs/what-is-access-review) module. This integration enables your organization to maintain comprehensive visibility over user access rights and streamline periodic access reviews for compliance and security.

<Callout kind="alert">
  Heads Up!

  The data synced from Copper flows into the **People → Access** module in Scrut.
</Callout>

## Prerequisites

Before starting the integration, ensure you have the following credentials:

- You must be a Scrut Admin (or Contributor with access to the Integrations module)
- Permissions to generate/access the API key in Copper

## How To Connect Copper With Scrut

### Step 1: Fetch API Key and Email Address from Copper

1. Log in to your Copper account and click your profile in the top-left and select **Integrations**.

2. In the **Settings** menu, navigate to **Integrations → API Keys**.
3. Click **Generate API Key**.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786430321986-tjen2i0ri5t-integrating-copper__02-click-generate-api-key.png?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="Click Generate API Key" caption=" " />
4. Copy the **API** **Key** and **Email** of the token creator (the email is available in the Creator field in the API key table). Save these details in a safe location, as you need to enter them in Scrut in the next step.

<Callout kind="info">
  Pro Tip!

  Refer to this guide from Copper for [more information on the API key and what it does](https://developer.copper.com/).
</Callout>

### Step 2: Go To Integrations in Scrut

1. [Sign in to Scrut](https://app.scrut.io/) and click **Integrations** on the left navigation panel.
2. Navigate to the **Integrations Library** tab, and choose **Customer Relationship Management** in the **Categories** section.
3. Scroll to the **Copper** tile and click **Integrate**.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786430325113-zva8aa02ym-integrating-copper__04-scroll-to-the-copper-tile-and-click-integrate.png?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="Scroll to the Copper tile and click Integrate" caption=" " />
4. On the integration page, paste the **API Key** and **Email** obtained in Step 1.
5. Click **Submit**.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786430326924-0j8md46o3db-integrating-copper__05-click-submit.png?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="Click Submit" caption=" " />
6. Once authorization is done, you’ll see the success toast and the **Connected** status indicator.

## Synchronization Details

- **Initial Sync**: Upon completing the integration, Scrut will start syncing user data from Copper. This process typically takes a few hours to complete. Check the Audit Log on the Copper integration page in Scrut to review the status.
- **Recurring Sync**: After this, Scrut performs a sync **every 24 hours** to fetch incremental data, such as new users, role changes, and permission updates.
- **Manual Sync**: You can also click the **Sync Now** button to trigger an immediate data refresh.

## Data Fetched from Copper

Scrut fetches the following access-related data points from Copper:

- User Name
- User Email
- User Role

## Viewing Copper Data in Scrut

To view the data fetched from your Copper account, go to the **People → Access → Overview** tab. On this page, you can see the user details for your Copper account.

You can also create an Access Review (or edit an existing one) and include the Copper application in scope. Refer to this guide for step-by-step instructions on [creating an access review](https://help.scrut.io/docs/creating-a-new-access-review).

Follow these steps to create a new access review for Copper:

1. Go to **People → Access** and click **Create New**.
2. Enter Review Details: Name, Description, Owner, and Review Days.
3. In step 2, search for and select Copper in the Applications in Scope.
4. Select **Reviewer** and **Approver**.
5. Review the details and click **Save Review**.

From the Access Review page, click Copper to view user details in Scrut.
