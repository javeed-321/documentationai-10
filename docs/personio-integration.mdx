title: "Integrate Personio"
---

Personio is a human resources management system (HRMS) that covers a wide range of HR functions. By integrating Personio with scrut platform, we can fetch the employee details in the scrut platform like Employee Name, email, department, reporting manager, joining date and exit date.

## Integrating Personio

1. From the left navigation panel, select Integrations.
2. Click on **Available**.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786432252556-duak5dzr19s-click-on-available-08e3709b.png?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="Click on Available" caption=" " />

3. Scroll to *Human Resource Information Systems* section and find *Personio*.
4. Click **Integrate**
<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786431781254-aem36vcizn4-personio-integration__02-click-integrate.png?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="Click Integrate" caption=" " />

5. Click **Connect**.
<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786431782884-gm226yokqom-personio-integration__03-click-connect.png?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="Click Connect" caption=" " />

6. Fill in the following details : 
* **Enter your Personio ClientID**: To generate your API credentials, go to Settings > API credentials. To know more, refer to this [link](https://developer.personio.de/docs/getting-started-with-the-personio-api).

* **Personio ClientSecret**: To generate your API credentials, go to Settings > API credentials. To know more, refer to this [link](https://developer.personio.de/docs/getting-started-with-the-personio-api).

* **Personio Application Identifier**  : While generating the credentials, you need to specify the Application Identifier that is passed to Personio in each app.
<Callout kind="info">
  Note:

  Values MUST follow the UPPER_JOHN_CASE format. For example MY_APPLICATION, ACME are valid values
</Callout>
<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786431784621-qn44o0t0tyl-personio-integration__04-values-must-follow-the-upper-john-case.png?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="Values MUST follow the UPPER_JOHN_CASE format. For example MY_APPLICATION, ACME are valid values" caption=" " />

7. Once the credentials are entered, click Submit.

Congrats! Your **Personio** account is successfully integrated with Scrut.

<Callout kind="info">
  **Info**:
  Employee data will start syncing immediately. Incremental data will be synced every 24 hours.
  Data can also be manually synced by clicking the three dots and choosing the Sync Now option.
</Callout>
