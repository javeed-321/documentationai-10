The **Scrut - Anthropic Claude** integration fetches user access data, permissions, and role assignments from your Anthropic Claude account and syncs them with the [Access Review](https://help.scrut.io/docs/what-is-access-review) module. This integration enables your organization to maintain comprehensive visibility over user access rights and streamline periodic access reviews for compliance and security.

<Callout kind="alert">
  Heads Up!

  The data synced from Anthropic Claude flows into the **People → Access** module in Scrut.
</Callout>

## Prerequisites

Before starting the integration, ensure you have the following credentials:

- You must be a Scrut Admin (or Contributor with access to the Integrations module)
- You must have permissions to generate an API key in Anthropic Claude

<Callout kind="info">
  Pro Tip!

  We recommend logging into your Anthropic Claude account before starting the integration to avoid doing so later.
</Callout>

## How To Connect Anthropic Claude With Scrut

### Step 1: Fetch API Key from Anthropic Claude

1. Log in to your organization’s [Anthropic Claude developer console](https://console.anthropic.com/) and click **API Keys** on the left navigation menu.
2. Click on **+Create Key**.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786429991053-gpgmztndpz6-integrating-anthropic-claude__01-click-on-create-key.png?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="Click on +Create Key" caption=" " />
3. Choose the Workspace and enter a name for the key, such as Scrut-Integration.
4. Click **Add**.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786429992756-iv1zpeminp8-integrating-anthropic-claude__02-click-add.png?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="Click Add" caption=" " />
5. Copy the API key code, as you won’t be able to see this later. Save the code in a safe location, as you’ll need to enter it in Scrut in the next step.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786429994573-48fslzh9aej-integrating-anthropic-claude__03-copy-the-api-key-code-as-you-wont-be-able-to.png?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="Copy the API key code, as you won’t be able to see this later" caption=" " />

<Callout kind="info">
  Pro Tip!

  Refer to this guide from Anthropic Claude for [more information on the API key and what it does](https://docs.anthropic.com/en/api/overview).
</Callout>

### Step 2: Go To Integrations in Scrut

1. [Sign in to Scrut](https://app.scrut.io/) and click **Integrations** on the left navigation panel.
2. Navigate to the **Integrations Library** tab, and choose **Miscellaneous** in the **Categories** section.
3. Scroll to the **Anthropic Claude** tile and click **Integrate**.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786429996396-oivdk6xyyy-integrating-anthropic-claude__04-scroll-to-the-anthropic-claude-tile-and.png?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="Scroll to the Anthropic Claude tile and click Integrate" caption=" " />
4. On the integration page, paste the API key obtained in [Step 1](/docs/integrating-anthropic-claude#step-1-fetch-api-key-from-anthropic-claude).
5. Click **Submit**.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786429998017-u2exvjm77m-integrating-anthropic-claude__05-click-submit.png?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="Click Submit" caption=" " />
6. Once authorization is done, you’ll see the “**Connected Successfully**” message and the **Connected** status indicator.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786429999690-l3zla6d4gne-integrating-anthropic-claude__06-once-authorization-is-done-youll-see-the.png?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="Once authorization is done, you’ll see the “Connected Successfully” message and the Connected status indicator" caption=" " />

## Synchronization Details

- **Initial Sync**: Upon completing the integration, Scrut will start syncing user data from Anthropic Claude. This process typically takes a few hours to complete. Check the Audit Log on the Anthropic Claude integration page in Scrut to review the status.
- **Recurring Sync**: After this, Scrut performs the sync once **every 24 hours** to fetch incremental data such as new users, role changes, and permission updates.
- **Manual Sync**: You can also click the **Sync Now** button to trigger an immediate data refresh.

## Data Fetched from Anthropic Claude

Scrut fetches the following access-related data points from Anthropic Claude:

- User Name
- User Email
- User Role

## Viewing Anthropic Claude Data in Scrut

To view the data fetched from your Anthropic Claude account, go to the **People → Access → Overview** tab. On this page, you can see the user details for your Anthropic Claude account.

You can also create an Access Review (or edit an existing one) and include the Anthropic Claude application in scope. Refer to this guide for step-by-step instructions on [creating an access review](https://help.scrut.io/docs/creating-a-new-access-review).

Follow these steps to create a new access review for Anthropic Claude:

1. Go to **People → Access** and click **Create New**.
2. Enter Review Details: Name, Description, Owner, and Review Days.
3. In step 2, search for and select Anthropic Claude in the Applications in Scope.
4. Select **Reviewer** and **Approver**.
5. Review the details and click **Save Review**.

From the Access Review page, click Anthropic Claude to view user details in Scrut.
