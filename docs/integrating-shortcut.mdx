Shortcut integration enables users to create compliance tasks/issues in Shortcut directly from the Scrut platform.

## Integrating Shortcut

1. From the left navigation panel, select Integrations.
2. Click on **Available**. <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786432252556-duak5dzr19s-click-on-available-08e3709b.png?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="Click on Available" caption=" " />
3. Scroll to *Project Management Platforms* section and find *Shortcut*.
4. Click **Integrate**. <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786431247512-1gh1tt19z3p-integrating-shortcut__02-click-integrate.png?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="Click Integrate" caption=" " />
5. In *API Token* field, enter your shortcut account API Token.

How to obtain API Token?

Refer to this [Shortcut Guide](https://help.shortcut.com/hc/en-us/articles/205701199-Shortcut-API-Tokens) for obtaining API Token.

6. Click **Submit**.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786431249540-d651fiso63u-integrating-shortcut__03-click-submit.png?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="Click Submit" caption=" " />

7. Upon successful integration you will see a connected flag in the integration page.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786431251489-fjrgv6rvger-integrating-shortcut__04-upon-successful-integration-you-will-see-a.png?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="Upon successful integration you will see a connected flag in the integration page" caption=" " />
