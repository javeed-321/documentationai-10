<Callout kind="info">
  Who can use this feature

  - Supported on **Foundation, Growth,** and **Scale** plans
</Callout>

Making individual changes to policies can often become repetitive, tedious, and time-intensive. To streamline this process, Scrut offers a **bulk actions** feature that enables users to apply changes to multiple policies at once. This article provides a comprehensive overview of how to utilize the bulk action feature and outlines the various actions that are available.

## How to Use the Bulk Action Feature

[Sign in to Scrut](https://app.scrut.io/login), and go to **Policies → All Policies** using the left navigation panel.

Select one or more policies that you want to modify. Available bulk actions are displayed at the top of the table.

You can perform the following bulk actions:

### Bulk Edit

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786431841833-6p4w47tp3wm-bulk-action-feature__02-bulk-edit.png?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="Bulk Edit" caption=" " />

Once you select the policies, click the consolidated <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786432288155-k9frmuyktv-pencil-icon-37db2f75.png?fm=auto&auto=compress%2Cformat" width="20" height="20" alt="Pencil icon" caption=" " />Edit option at the top. You can bulk update various policy features, such as:

- **Assignees:** Choose one or more assignees for the policies and click **Make Primary** to designate a Primary Assignee.
- **Approvers**: You can add up to five approvers for a policy. Drag and drop approvers to arrange them in hierarchical order. You can update approvers only for policies that aren’t in the Published state.
- **Entities:** Link the selected policies to the desired entities.
- **Recurrence:** Set the policy recurrence schedule: Annually, Biannually, Quarterly, Monthly, or Never.
- **Department:** Modify the departments for selected policies in one go.
- **Next Review Date:** Set the next review date for the selected policies. This option is only available for policies in the **Published** or **Needs Review** status.
- **Relevance:** Mark all selected policies as relevant or not relevant.

<Callout kind="alert">
  Note:

  If you don’t want to modify a particular field, leave it unchanged. Scrut will retain the existing value for it, and update other fields that you have specifically modified.
</Callout>

<Callout kind="info">
  Pro Tip!

  To monitor changes, click on any policy to access its audit log. The log will display the user who made the changes, and the changes made.
</Callout>

### Bulk Publish

To bulk publish, select the required policies and click the consolidated **Publish** button at the top.

<Callout kind="alert">
  Note:

  The bulk publish button is available only when at least one of the selected policies are in approved state.
</Callout>

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786431845319-tl2ctcrryxn-bulk-action-feature__05-the-bulk-publish-button-is-available-only.gif?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="The bulk publish button is available only when at least one of the selected policies are in approved state" caption=" " />

### Bulk Export Attachments

Select the policies for which you want to export attachments, and click the consolidated **Export Attachments** button at the top. Scrut lists the policies that have attachments. Confirm the action, and you will receive the attachments to your email.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786431846953-7a9mrbaheq-bulk-action-feature__06-select-the-policies-for-which-you-want-to.gif?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="Select the policies for which you want to export attachments, and click the consolidated Export Attachments" caption=" " />

### Bulk Delete

Select the policies you want to delete, and click the consolidated **Delete** button at the top.

<Callout kind="danger">
  Note:

  This action is permanent, so proceed with caution.
</Callout>
