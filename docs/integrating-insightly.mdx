The **Scrut - Insightly** integration fetches user access data, permissions, and role assignments from your Insightly account and syncs them with the [Access Review](https://help.scrut.io/docs/what-is-access-review) module. This integration enables your organization to maintain comprehensive visibility over user access rights and streamline periodic access reviews for compliance and security.

<Callout kind="alert">
  Heads Up!

  The data synced from Insightly flows into the **People → Access** module in Scrut.
</Callout>

## Prerequisites

Before starting the integration, ensure you have the following credentials:

- You must be a Scrut Admin (or Contributor with access to the Integrations module)
- An Insightly account with permissions to generate an API Key

**Note:** If you don’t have access to the User Settings in Insightly, you’ll need to contact your Insightly administrator to generate an API key.

<Callout kind="info">
  Pro Tip!

  We recommend logging into your Insightly account before starting the integration to avoid doing so later.
</Callout>

## How To Connect Insightly With Scrut

### Step 1: Fetch API Key and URL from Insightly

1. Log in to your Insightly account and click your **Profile** icon in the top-right corner.
2. Select **User Settings** from the dropdown menu.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786430681051-70uvm8b6nfx-integrating-insightly__01-select-user-settings-from-the-dropdown-menu.png?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="Select User Settings from the dropdown menu" caption=" " />
3. In the User Settings page, scroll to the **API section** and locate your **API key**.
4. **Copy the API key** and store it securely.
5. Also, note your **API URL**, which indicates your pod. e.g., https://api.na1.insightly.com/v3.1/
6. The pod identifier (na1, au1, eu1, etc.) is important for API configuration.
7. Copy the API Key and URL and save them in a safe location. You must enter them in Scrut in the next step.

You must enter them in Scrut in the next step" caption=" " />

### Step 2: Go To Integrations in Scrut

1. [Sign in to Scrut](https://app.scrut.io/) and click **Integrations** on the left navigation panel.
2. Navigate to the **Integrations Library** tab, and choose **Customer Relationship Management** in the **Categories** section.
3. Scroll to the **Insightly** tile and click **Integrate**.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786430684659-bw36ot36wgi-integrating-insightly__03-scroll-to-the-insightly-tile-and-click.png?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="Scroll to the Insightly tile and click Integrate" caption=" " />
4. On the integration page, paste the **API Key** and **API URL** obtained in Step 1.
5. Click **Submit**.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786430686213-928101zkrni-integrating-insightly__04-click-submit.png?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="Click Submit" caption=" " />
6. Once authorization is done, you’ll see the success toast and the **Connected** status indicator.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786430687908-tc483ys63im-integrating-insightly__05-once-authorization-is-done-youll-see-the.png?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="Once authorization is done, you’ll see the success toast and the Connected status indicator" caption=" " />

## Synchronization Details

- **Initial Sync**: Upon completing the integration, Scrut will start syncing user data from Insightly. This process typically takes a few hours to complete. Check the Audit Log on the Insightly integration page in Scrut to review the status.
- **Recurring Sync**: After this, Scrut performs a sync **every 24 hours** to fetch incremental data, such as new users, role changes, and permission updates.
- **Manual Sync**: You can also click the **Sync Now** button to trigger an immediate data refresh.

## Data Fetched from Insightly

Scrut fetches the following access-related data points from Insightly:

- User Name
- User Email
- User Role

## Viewing Insightly Data in Scrut

To view the data fetched from your Insightly account, go to the **People → Access → Overview** tab. On this page, you can see the user details for your Insightly account.

You can also create an Access Review (or edit an existing one) and include the Insightly application in scope. Refer to this guide for step-by-step instructions on [creating an access review](https://help.scrut.io/docs/creating-a-new-access-review).

Follow these steps to create a new access review for Insightly:

1. Go to **People → Access** and click **Create New**.
2. Enter Review Details: Name, Description, Owner, and Review Days.
3. In step 2, search for and select Insightly in the Applications in Scope.
4. Select **Reviewer** and **Approver**.
5. Review the details and click **Save Review**.

From the Access Review page, click Insightly to view user details in Scrut.
