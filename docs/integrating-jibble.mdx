The **Scrut - Jibble** integration fetches user access data and role assignments from your Jibble account and syncs them with the [Access Review](https://help.scrut.io/docs/what-is-access-review) module. This integration enables your organization to maintain comprehensive visibility over user access rights and streamline periodic access reviews for compliance and security.

<Callout kind="alert">
  Heads Up!

  The data synced from Jibble flows into the **Access Review** module in Scrut.
</Callout>

## Prerequisites

Before starting the integration, ensure you have the following access and permissions:

### Access

- You must be a Scrut Admin (or Contributor with access to the Integrations module)
- You must have permissions to generate an API key in Jibble

### Permissions

Scrut requires **read-only access** to the following data in Jibble

- User Accounts: View name, email, and user role

<Callout kind="info">
  Pro Tip!

  We recommend logging into your Jibble account before starting the integration to avoid doing so later.
</Callout>

## How To Connect Jibble With Scrut

### Step 1: Fetch API Key & Secret from Jibble

1. Log in to your Jibble account.
2. Expand the **Settings** menu in the side navigation bar and click **Organization**.
3. Navigate to the **API Credentials** tab.
4. Click **Create New Secret.**

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786430702962-oz0hwrzh4x-integrating-jibble__01-click-create-new-secret.png?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="Click Create New Secret" caption=" " />
5. Enter the **Name** and click **Save**.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786430704587-x7yyadg7keb-integrating-jibble__02-enter-the-name-and-click-save.png?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="Enter the Name and click Save" caption=" " />
6. Copy the **API Key ID** and **API Key Secret** displayed on screen, as they won’t be shown later.
7. Save it in a safe location, as you’ll need to enter it in Scrut in the [next step](/v1/docs/integrating-jibble#step-2-go-to-integrations-in-scrut).

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786430706431-moqt217bv9-integrating-jibble__03-save-it-in-a-safe-location-as-youll-need-to.png?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="Save it in a safe location, as you’ll need to enter it in Scrut in the next step" caption=" " />

**Note:** Refer to this guide from Jibble for [more information on the API key and what it does](https://www.jibble.io/help/using-jibbles-api-for-your-custom-needs).

### Step 2: Go To Integrations in Scrut

1. [Sign in to Scrut](https://app.scrut.io/) and click **Integrations** on the left navigation panel.
2. Navigate to the **Integrations Library** tab, and choose **Human Resource Information System (HRIS)** in the **Categories** section.
3. Scroll to the **Jibble** tile and click **Integrate**.
4. On the integration page, paste the API key and secret obtained in [Step 1](/v1/docs/integrating-jibble#step-1-fetch-api-key-secret-from-jibble).

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786430708156-00sxfnpm55x-integrating-jibble__04-on-the-integration-page-paste-the-api-key.png?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="On the integration page, paste the API key and secret obtained in Step 1" caption=" " />
5. Click **Submit**.
6. Once authorization is done, you’ll see the success toast message and the **Connected** status indicator.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786430709910-cfx8jbjxim4-integrating-jibble__05-once-authorization-is-done-youll-see-the.png?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="Once authorization is done, you’ll see the success toast message and the Connected status indicator" caption=" " />

## Synchronization Details

- **Initial Sync**: Upon completing the integration, Scrut will start syncing user data from Jibble. This process typically takes a few hours to complete. Check the Audit Log on the Jibble integration page in Scrut to review the status.
- **Recurring Sync**: After this, Scrut performs the sync once **every 24 hours** to fetch incremental data such as new users, role changes, and permission updates.
- **Manual Sync**: You can also click the **Sync Now** button to trigger an immediate data refresh.

## Data Fetched from Jibble

Scrut fetches the following access-related data points from Jibble:

- User Name
- User Email
- User Role

## Viewing Jibble Data in Scrut

To view the data fetched from your Jibble account, go to the **People → Access → Overview** tab. On this page, you can see the user details for your Jibble account.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786430713396-cvnrj86z7j-integrating-jibble__07-to-view-the-data-fetched-from-your-jibble.png?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="To view the data fetched from your Jibble account, go to the People → Access → Overview tab" caption=" " />

You can also create an Access Review (or edit an existing one) and include the Jibble application in scope. Refer to this guide for step-by-step instructions on [creating an access review](https://help.scrut.io/docs/creating-a-new-access-review).

Follow these steps to create a new access review for Jibble:

1. Go to **People → Access** and click **Create New**.
2. Enter Review Details: Name, Description, Owner, and Review Days.
3. In step 2, search for and select Jibble in the Applications in Scope.
4. Select **Reviewer** and **Approver**.
5. Review the details and click **Save Review**.

From the Access Review page, click Jibble to view user details in Scrut.
