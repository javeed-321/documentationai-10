---
title: "Integrating Fleet"
---

Fleet integration fetches employees' endpoint/device data to Scrut. This data is displayed in the People Dashboard and the People -> Employee module. The following data is fetched from Fleet:

- Device name
- OS version
- Serial number
- Antivirus Installed(Yes/No)
- HD Encrypted(Yes/No)
- Screenlock Enabled(Yes/No)

## Integrating Fleet

1. From the left navigation panel, select Integrations.
2. Click on **Available**.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786432252556-duak5dzr19s-click-on-available-08e3709b.png?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="Click on Available" caption=" " />

3. Scroll to *Mobile Device Management Tools* section and find *Fleet*.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786430460861-a5rm1zdzuk7-integrating-fleet__02-scroll-to-mobile-device-management-tools.png?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="Scroll to Mobile Device Management Tools section and find Fleet" caption=" " />

4. Click **Integrate**. <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786430462573-kybth8t9u8b-integrating-fleet__03-click-integrate.png?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="Click Integrate" caption=" " />

Fleet integration page opens. <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1786430464437-bqruw43lj2g-integrating-fleet__04-fleet-integration-page-opens.png?fm=auto&auto=compress%2Cformat" width="800" height="600" alt="Fleet integration page opens" caption=" " />

5. In *URL* field, enter the full url of your fleet instance (e.g. https://fleet.acme.com)
6. In API Token field, enter the api token.

How to generate API Token?

Read the following [Fleet Guide](https://fleetdm.com/docs/using-fleet/fleetctl-cli#create-an-api-only-user) to generate API token.

7. Click on **Submit**.

Integration is successful.
