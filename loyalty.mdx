---
title: "Loyalty"
description: "Build custom loyalty programs with a points system and rules engine that configures point sources and accounts, delivers awards, moves customers between tiers, and triggers campaigns."
---

The Loyalty API specification is published as an interactive Swagger reference, where you can browse every endpoint, inspect request and response schemas, and try calls against the platform.

<Card title="Open the Loyalty API reference" href="https://domains-connecteast1.ent-sessionm.com/incentives/swagger/ui/index#/" icon="award" horizontal="false">
  APIs that control a robust points system and loyalty rules engine to create custom loyalty programs. Point sources and accounts can be configured, managed and audited. Rules are triggered by actions taken and can deliver awards, move customers between tiers and even trigger campaigns.
</Card>

<Callout kind="info">
  Before calling any endpoint, obtain your API key and S2S API secret. See [Before You Begin](/developer/before-you-begin).
</Callout>
