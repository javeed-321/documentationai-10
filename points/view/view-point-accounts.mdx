View high-level information about point accounts, including name, status and sources.

## Steps

1. From the main SessionM dashboard, select **Points Management**.
2. Select **Point Accounts**.

The Point Accounts tab displays detailed information, as described below.

## Detailed information

- **Name** – Only visible internally. Descriptive name that identifies the account when linking to point sources, setting up loyalty rules or viewing reports.
- **Status** – Active or Inactive. Accounts are set to Active when created.
- **Default** – Yes or No. Yes means that spend operations automatically deduct from the point account.
- **Sources** – Number of point sources that feed the point account. There is no limit to the number of point sources that can feed a point account, and the same point source can feed multiple point accounts.
- **Actions** – Available actions depend on the status of the point account. Active accounts can be edited and deactivated. Inactive accounts can only be activated.
