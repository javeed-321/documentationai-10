View high-level information about your point sources, including names, status and accounts.

## Steps

1. From the main SessionM dashboard, select **Points Management**.
2. Select **Point Sources**.

The Point Sources tab displays detailed information, as described below.

## Details

- **Name** – Only visible internally. Descriptive name that identifies the source when linking to point accounts, setting up loyalty rules or viewing reports.
- **Status** – Active, Paused or Archived. Sources are set to Active when created.
  - **Active** – Point source is active as long as inventory is above zero — or there is no inventory restriction, making it unlimited. Only active point sources are available to be assigned in the platform, such as being linked to point accounts or used in loyalty rules.
  - **Paused** – Point source that has been manually paused or moved to a paused state because the inventory reached zero. When paused, no points can be issued from the source. The source can be set back to active (unless point balance remains at zero) or archived from a paused state. Note that pausing a point source has downstream impacts to existing campaigns, economy rules, and loyalty rules.
  - **Archived** – Point source can move into archived state from either an active or paused position. You must confirm the archive request since archiving immediately expires any remaining current inventory.
- **Accounts** – Indicates how many point accounts the source is linked to. There is no limit to the number of point accounts a source can feed into, and the same source can feed multiple accounts.

  <Callout kind="info">
    By default, when a new point source is created, it is linked to all existing point accounts. You can change this during source creation or go back and edit the source at any time.
  </Callout>

- **Actions** – Available actions are determined by the state. Active sources can be edited, paused and archived. Paused and Archived accounts can only be activated.
