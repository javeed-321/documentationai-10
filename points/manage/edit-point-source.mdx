Edit an existing point source.

## Before You Start

Basic information on the point source has been defined. For more information, see [Create Point Source](/points/create/create-point-source).

## Steps

1. On the Point Sources tab of the Point Management page, locate the point source you want to edit.
2. In the Actions column, click **edit** for the point source. The Edit Point Source page displays.
3. Modify the point source. For more information, see [Create Point Source](/points/create/create-point-source).
4. Click **Save**.
