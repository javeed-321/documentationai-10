---

Activate, pause or archive a point source.

## Steps

1. On the Point Sources tab of the Point Management page, locate the point source.
2. If you want to activate the point source:
   1. In the Actions column, click **activate** for the source. The Confirm Activation modal displays.
   2. Click **Activate**. The system displays a message that the point source has been activated. A new option to deactivate the source displays in the Actions column for the point source.
3. If you want to pause the point source:
   1. Click **pause** for the source in the Actions column. The Confirm Pause modal displays.
   2. Click **Pause**. The system displays a message that the point source has been paused. Only the option to activate the source displays in the Actions column for the point source.
4. If you want to archive the point source:
   1. Click **archive** for the source in the Actions column. The Confirm Archive modal displays.
   2. Click **Archive**. The system displays a message that the point source has been archived. Only the option to activate the source displays in the Actions column for the point source.
