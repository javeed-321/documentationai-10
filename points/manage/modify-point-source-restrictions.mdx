Change or delete point source restrictions.

## About this task

After you configure an inventory restriction, you may need to change the specified inventory amount by making modifications on the Edit Point Source Inventory Restriction page. Increase inventory by entering a positive number in the Modification field. Reduce inventory by entering a negative number.

## Before you start

Point source restrictions have been defined. For more information, see [Create Point Source](/points/create/create-point-source).

## Steps

1. On the Point Sources tab of the Point Management page, locate the point source with the restrictions you want to edit.
2. In the Actions column, click **edit** for the source. The Edit Point Source page displays.
3. In the Point Source Restrictions table, locate the restriction you want to edit or delete.
4. If you want to edit the restriction:
   1. In the Actions column, click **edit** for the restriction. Depending on what type of restriction you are modifying, the appropriate edit restriction page displays.
   2. Modify the source restriction.
5. If you want to delete the restriction:
   1. In the Actions column, click **delete** for the restriction. The Confirm Deletion modal displays.
   2. Click **Delete**. The system displays a message that the point source restriction has been deleted, and the restriction is removed from the Point Source Restrictions table.
6. When you are done editing or deleting restrictions, click **Save** on the Edit Point Source page.
