Edit an existing point account.

## Before you start

The point account has been created and is not yet activated. Only deactivated accounts can be edited. For more information, see [Create Point Account](/points/create/create-point-account) and [Activate or Deactivate Point Account](/points/manage/activate-or-deactivate-point-account).

## Steps

1. On the Point Accounts tab of the Point Management page, locate the point account you want to edit.
2. In the Actions column, click **edit** for the point account. The Edit Point Account page displays.
3. Modify the point account. For more information, see [Create Point Account](/points/create/create-point-account).
4. Click **Save**.
