---
title: "View behavior or message details"
description: "View details for all customer behaviors or messages defined for a campaign using the summary panel."
---

View details for the customer behaviors or messages defined for a campaign. Note that the details shown reflect ALL of the behaviors or messages included in the campaign.

## Steps

1. From a campaign's main page, select the **View Details** link that displays in both the Customer Behavior or Messages areas of the page. This action opens a summary panel that slides into view and provides the user with a summary of behavior and message details.
2. Close the summary panel by clicking either its close (X) button or a screen location anywhere outside of the panel.
