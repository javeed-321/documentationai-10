---
title: "Target campaign"
description: "Define which customers are eligible to participate in a campaign by targeting all users, a segment, or a targeting template."
---

Define a target to determine which customers are eligible to participate in a campaign. The target can be all users or a segment of users. By default, campaigns are targeted to all users. You can also target the campaign based on a template of attributes.

<Callout kind="info">
  Targeting at the campaign level creates the basic audience pool for the campaign and any messages. Further targeting at the message level can only reduce the audience targeted to receive that message. This may seem counter-intuitive. For example, if you include a snapshot at the message level, you might expect that to increase the total audience receiving that message, but it would only keep the size the same or reduce it. The system does not target everyone in that included snapshot; it targets only those people in the included snapshot who are also in the audience pool set by the campaign-level targeting, thus reducing the total audience size for that message.
</Callout>

## Before you start

- If you plan to use a pre-existing audience or snapshot, make sure that the audience or snapshot has been defined in the Audience module.

<ExpandableGroup>
  <Expandable title="Target by segment" default-open="false">
    1. From the Setup tab, click **Edit Targeting** in the Target Audience section.
    2. On the Edit Targeting Audience page, select **Target by Segment**.
    3. Use the **All Any** toggle to specify which of the following conditions is required to generate the customer audience from the segments or the attribute groups that contain segments:
       - **All** - Applies an ADD relationship between all segments or attribute groups containing segments.
       - **Any** - Applies an OR relationship between all segments or attribute groups containing segments.
    4. Select a segment from the **Add Segment** drop-down to add a card for the segment. Note that you can search for fields by entering letters into the Add Segment field.
       - If you select **Appended Data**, the Custom Attribute Selector opens. With it, you can navigate existing categories of appended data to locate the attribute you need and then add the attribute to your audience.

    <Callout kind="info">
      The Include/Exclude toggle appears when a segment has multiple values. By default, Include is enabled, meaning that the values you select are included in the audience definition. If you toggle this button to Exclude, the selected values are excluded from the audience definition. This is useful, for example, if you want all states but Alaska and Hawaii. Toggle to Exclude, then select these two states from list. Alaska and Hawaii are not included in the audience definition.
    </Callout>

    5. Repeat step 4 to add as many segments as needed to define the segment.
    6. Between the segments you create, indicate if the segments are combined in an AND or an OR relationship. As segments are defined, they appear in the Targeting Summary, along with the real-time, estimated audience size above.
    7. Now, if you want any of the segments to reside together in a group, click **+ Add Attribute Group**. Each segment card now displays a checkbox you can enable to assign the segment to an attribute group.
    8. Once you've enabled the segments being added to the group, click **Done**. Doing so designates an OR relationship between the segments in the attribute group; a red line appears to the left of the group members.
    9. If you want to save your segment targeting definition as a template, click **Templates**. In the Targeting Templates modal, click **Save a Template**. Give the template a name and a description. Click **Save**.
    10. Back on the Campaign Targeting page, if you are done adding segments or attribute groups containing segments, click **Save**.
  </Expandable>

  <Expandable title="Target by template" default-open="false">
    A **_targeting template_** is a complete definition of an audience that you can use in multiple campaigns. You can apply a set of attributes from an existing template or save a set of attributes as a new template when selecting a campaign target. The template can be used when targeting either all users or by segment.

    1. From the Edit Targeting Audience page, select **Templates** to open the Targeting Templates modal.
    2. On the Select a Template tab, choose a targeting template.
    3. If you want to either delete or rename the template, click the **Quick Action button** that displays at the far right of the template's table row and select either **Delete** or **Rename**.
    4. Click **Apply**. The attributes associated with that targeting template are added to your targeting selections.
    5. Back on the Campaign Targeting page, If desired, add segments to further define the target audience.
    6. Click **Save**.
  </Expandable>
</ExpandableGroup>
