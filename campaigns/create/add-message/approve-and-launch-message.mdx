---
title: "Approve and launch message"
description: "Approve and launch a campaign message directly, or request approval from a user with the required permissions."
---

When you define a message for a campaign, you can leave the message in its default "Draft" state, or you can get it approved as well as launched. If you choose not to approve and launch a message on its own, it will be approved and launched into an "Active" state when the campaign is launched.

As a user, if you do not have permissions that support an approval of a message, you request that someone else approves it. For the purposes of discussion, this flow is one that has a _submitting_ user requesting approval for a message from an _approving_ user.

## Steps

1. From the message's main page, the _submitting_ user can click **Get Approval**. Doing so, moves the message from "Draft" to "In Review."
2. Next, an _approving_ user with platform permissions for approving messages can click **Approve** if they believe the message is ready to be included with the campaign. This action moves the message into a "Pending" state.

   Alternatively, the _approving_ user can click **Reject**, thereby putting the message into a state of "Rejected." At this point, the message could be revised in an effort to address whatever concerns led to it being rejected. Once revised, the message could be returned to the _approving_ user by clicking **Get Approval** again, as described in step 1.

3. Now the user that approved the message can click **Launch**. The messages is now in an "Active" state.
4. If you want to pause an active message, access it from its linked name, which appears in the Messages section of the campaign's main page. Click **Pause** to place the message into a "Paused" state. You can make the message resume its "Active"state by clicking **Resume**.
