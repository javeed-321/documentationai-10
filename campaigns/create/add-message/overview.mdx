---
title: "Add message"
description: "Complete the tasks required to add a message to a campaign, from selecting the message type through approving and launching it."
---

Complete the following tasks to add a message to a campaign:

1. [Select message type.](/campaigns/create/add-message/select-message-type)
2. [Set up message delivery](/campaigns/create/add-message/set-up-message-delivery).
3. [Add creative content.](/campaigns/create/add-message/add-creative-content)
4. [Select target for message.](/campaigns/create/add-message/select-target-for-message)
5. [Document message](/campaigns/create/add-message/document-message) This is optional
6. [Approve and launch message](/campaigns/create/add-message/approve-and-launch-message). This is optional.
