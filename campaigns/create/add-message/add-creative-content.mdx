---
title: "Add creative content"
description: "Add creative content to a campaign message — activity feed, inbox, email, SMS, push, external message or in app notification."
---

Add creative content to a message.

<ExpandableGroup>
  <Expandable title="Add creative content to activity feed" default-open="false">
    1. On the activity feed's builder page, click **Creative**.
    2. Enter data in the following fields on the Creative tab.

       | Field | Description |
       | --- | --- |
       | Header | Title of message in tile served by feed. |
       | SubHeader | Subtitle of message in tile served by feed. |
       | Points | Number of points awarded for clicking on tile. |
       | Additional Copy | Additional text that displays on tile. |
       | Action | Action that happens when customer clicks on tile. For example, going to external web page or accessing a deep link in an app. |
       | External Link | Changes with respect to action selected above. Defaults to External Link . If action is set to Execution , an "Execution" dropdown would show all executions you have set up such as videos and graphical displays. |
       | Display Points | Points to let customer know what they can earn for engaging with tile; not the points they actually get. |
       | Content Url | URL to formatting template for how tile displays. |
       | App Icon | Icon image showing in tile that reflects related app, such as Facebook. |
       | App Icon Alt Text | Alternative text when icon cannot display. |
       | Graphic | Image that displays in tile. |
       | Graphic Alt Text | Alternative text when image cannot display. |
       | Link to externally hosted Legal or Terms and Conditions pages | URL to related legal or terms/conditions page. |

    3. Click **Save**.
  </Expandable>

  <Expandable title="Add creative content to inbox message" default-open="false">
    1. On the inbox message's builder page, click **Creative**.
    2. Enter a **Header**, which specifies routing information for the message, including the sender, recipient, date and subject.
    3. Enter a **Message**.
    4. For **Icon**, drop, browse or upload a file.
    5. Click **Save**.
  </Expandable>

  <Expandable title="Add creative content to email message" default-open="false">
    1. On the email message's builder page, click **Creative**.
    2. Select a **Message Provider**, which is the service partner participating in the email integration. The provider you select determines which creative templates display in the Templates dropdown.
    3. Select a template.
    4. Select the template variant (if you want to use a template other than the default).
    5. Click **Save**.
  </Expandable>

  <Expandable title="Add creative content to SMS message" default-open="false">
    1. On the SMS message's builder page, click **Creative**.
    2. Enter a **Message Provider**, which is the service partner participating in the SMS message integration.
    3. Select a **Target Phone Number** that receives the SMS message. This selection is from a dropdown that corresponds to the message provider you selected.
    4. Select a **Messaging Preference**.
    5. In **Message**, enter text for the SMS message.
    6. Click **Save**.
  </Expandable>

  <Expandable title="Add creative content to push notification - legacy" default-open="false">
    1. On the push notification's builder page, click **Creative**.
    2. Enter text for the **Header** that displays in the notification.
    3. In **Message**, enter text for the notification message.
    4. Select the **Action** that you want the customer to perform.
    5. Click **Save**.
  </Expandable>

  <Expandable title="Add creative content to external message" default-open="false">
    1. On the external message's builder page, click **Creative**.
    2. Enter a **Message Provider**, which is the service partner participating in the external message integration.
    3. Select a template for the message. This selection is from a dropdown that corresponds to the message provider you selected.
    4. Select the template variant (if you want to use a template other than the default).
    5. Click **Save**.
  </Expandable>

  <Expandable title="Add creative content to in app notification" default-open="false">
    1. On the in app notification's builder page, click **Creative**.
    2. Enter text for the **Header** that displays in the notification.
    3. In **Message**, enter text for the notification message.
    4. Enter **Button Text** that appears for a button included in the notification.
    5. Click into **Button Color** to open a color picker and set the color of a button included in the notification.
    6. Select the **Action** by which the customer can engage with from the notification.
    7. Drop, browse or upload the **Push Icon** that you want to be shown on the notification.
    8. Drop, browse or upload the **Push Graphic** that you want to be shown on the notification.
    9. Click **Save**.
  </Expandable>

  <Expandable title="Add creative content to push message" default-open="false">
    1. On the push message's builder page, click **Creative**.
    2. On the Creative tab, select the message provider from the dropdown list.
    3. Enter text for the **Header** that displays in the push message.
    4. In **Message**, enter text for the push message.
    5. Select the **Action** that you want the customer to perform.
    6. Optionally, specify the Apple Notification Service (APNS) Config.
    7. Optionally, specify the Firebase Cloud Messaging (FCM) Config.
    8. Click **Save**.
  </Expandable>
</ExpandableGroup>
