---
title: "Document message"
description: "Track free-form notes about a campaign message using the Notes tab of the message builder. This step is optional."
---

Track any additional, free-form information about the message that you would like to remember. This step is optional.

## Steps

1. From any tab of the message builder page, click **Notes** to open the Notes tab and display a text box.
2. Write the note.
3. Click **Add Entry** to add it to the All Notes section of the page.
