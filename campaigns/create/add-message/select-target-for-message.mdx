---
title: "Select target for message"
description: "Refine message targeting to focus on a particular audience or user attributes within the campaign's existing audience pool."
---

By default, messages are targeted based on existing campaign targeting. You can refine the targeting so it is focused on a particular audience or on one or more particular user attributes.

<Callout kind="info">
  Targeting at the campaign level creates the basic audience pool for the campaign and any messages. Further targeting at the message level can only reduce the audience targeted to receive that message. This may seem counter-intuitive. For example, if you include a snapshot at the message level, you might expect that to increase the total audience receiving that message, but it would only keep the size the same or reduce it. The system does not target everyone in that included snapshot; it targets only those people in the included snapshot who are also in the audience pool set by the campaign-level targeting, thus reducing the total audience size for that message.
</Callout>

## Before you start

- If you plan to use a pre-existing audience or snapshot, make sure that the audience or snapshot has been defined in the Audience module.

## Steps

1. On the message builder page, select the Targeting tab.
2. Select **Refine Segment**.
3. See [Target campaign](/campaigns/create/target-campaign) for further instructions.
