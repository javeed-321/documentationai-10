---
title: "Select message type"
description: "Select and configure the type of message delivered to campaign participants, from graphic displays and push messages to bulk offers."
---

Select the type of message delivered to campaign participants.

<ExpandableGroup>
  <Expandable title="Configure graphic display" default-open="false">
    A graphic display is a static, interstitial display rendered within a mobile app. It can include a destination URL or deep link for the customer to click through.

    1. From the campaign's setup tab, click **Add Message**.
    2. On the Select Message Type popup, select **Graphic Display**.
    3. On the Setup tab of the Graphic Display page, enter the display name.
    4. In Event Tags, add one or more tags that indicate when a customer has interacted with the graphic display. As you type your tag names in the field, the system searches for matching tags.
    5. Click **Save**
  </Expandable>

  <Expandable title="Configure activity feed" default-open="false">
    An activity feed is a stream of events that reflect a customer's online interactions with a campaign message.

    1. From the campaign's setup tab, click **Add Message**.
    2. On the Select Message Type popup, select **Activity Feed** and click **OK**.
    3. On the Setup tab of the Activity Feed page, enter the display name.
    4. Specify the start and end dates (and times) of the feed.
    5. If you want to trigger the activity feed with a behavior, click **Trigger by a behavior**. For more information, see [Define Behaviors](/campaigns/create/define-behaviors).
    6. For Frequency Caps, define the number of times this message can be shown to an enduser in the specified period of time. Default is "Unlimited." The "Limited" option allows you to constrain how many times the message will be shown.
    7. If you want to specify a weight that expresses what priority should be applied to the activity feed with respect to other feeds, assign a number in the Weight field.
    8. If you want to make a specific tile appear in the feed, name the tile with a tag In the Tile Tag field. Only one feed tile with this name will appear to the customer viewing the feed.
    9. In the Event Tags field, add one or more tags that indicate when a customer has interacted with this campaign message. As you type your tag names in the field, the system searches for matching tags.
    10. In the Event Name field, specify a name for the event that corresponds to the customer's interaction with this campaign message.
    11. Click **Save**
  </Expandable>

  <Expandable title="Configure inbox message" default-open="false">
    A graphic display is a static, interstitial display rendered within a mobile app. It can include a destination URL or deep link for the customer to click through. Inbox messages are sent to a mobile app inbox and delivered the next time a customer logs into the app (after the defined send time/date). Inbox messages consist of a header and a message body.

    Note that implementing this type of message requires use of the SessionM SDK.

    1. From the campaign's setup tab, click **Add Message**.
    2. On the Select Message Type popup, select **Inbox Message**.
    3. On the Setup tab of the Push Message page, select a Delivery Method. See [Set up message delivery](/campaigns/create/add-message/set-up-message-delivery) for guidance.
    4. In Event Tags, add one or more tags that indicate when a customer has interacted with the message. As you type your tag names in the field, the system searches for matching tags.
    5. Click **Save**
  </Expandable>

  <Expandable title="Configure push message" default-open="false">
    Push messages are sent directly to a customer's mobile device at any time regardless of whether or not the customer is actively using the device or a specific app.

    1. From the campaign's setup tab, click **Add Message**.
    2. On the Select Message Type popup, select **Push Message**.
    3. On the Setup tab of the Push Message page, select a Delivery Method. See [Set up message delivery](/campaigns/create/add-message/set-up-message-delivery) for guidance.
    4. Click **Save**.
  </Expandable>

  <Expandable title="Configure email message" default-open="false">
    1. From the campaign's setup tab, click **Add Message**.
    2. On the Select Message Type popup, select **Email Message**.
    3. On the Setup tab of the Email Message page, specify the email address that displays as the email's From Email Address and the name that displays as the email's From Name.
    4. In Reply Email Address, enter the address that customers can use to reply to the email.
    5. Add a subject for the email in Subject.
    6. Select a **Delivery Method**. See [Set up message delivery](/campaigns/create/add-message/set-up-message-delivery) for guidance.
    7. In Event Tags, add one or more tags that indicate when a customer has interacted with the message. As you type your tag names in the field, the system searches for matching tags.
    8. Click **Save**.
  </Expandable>

  <Expandable title="Configure SMS message" default-open="false">
    An SMS message is a text messaging service component of most telephone, internet, and mobile-device systems. It uses standardized communication protocols to enable their reception by mobile devices.

    1. From the campaign's setup tab, click **Add Message**.
    2. On the Select Message Type popup, select **SMS Message**.
    3. On the Setup tab of the SMS Message page, select a **Delivery Method**. See [Set up message delivery](/campaigns/create/add-message/set-up-message-delivery) for guidance.
    4. Click **Save**.
  </Expandable>

  <Expandable title="Configure push notification - legacy" default-open="false">
    Push notifications are sent directly to a customer's mobile device at any time regardless of whether or not the customer is actively using the device or a specific app.

    1. From the campaign's setup tab, click **Add Message**.
    2. On the Select Message Type popup, select **Push Notification - legacy**.
    3. On the Setup tab of the Push Notification page, enter a Display Name for the push notification.
    4. Select a **Delivery Method**. See [Set up message delivery](/campaigns/create/add-message/set-up-message-delivery) for guidance.
    5. Click **Save**.
  </Expandable>

  <Expandable title="Configure external message" default-open="false">
    An external message is executed through an external integration, where the SessionM Platform instructs another system (email service provider, SMS provider, and so on) to send a message to a specific customer.

    You can also add an offer to be delivered with the external message. When the delivery time or triggered event arrives, the platform first issues the offer to the audience and then sends the external message.

    1. From the campaign's setup tab, click **Add Message**.
    2. On the Select Message Type popup, select **External Message**.
    3. On the Setup tab of the External Message page, select a **Delivery Method**. See [Set up message delivery](/campaigns/create/add-message/set-up-message-delivery) for guidance.
    4. If you want to include an offer with the message, click **Select Offer**, select the offer from the list, and click **Save**.
    5. Click **Save**.
  </Expandable>

  <Expandable title="Configure in app notification" default-open="false">
    In App notifications are sent directly to a customer's mobile device and received by the customer only when they are using a specific app.

    1. From the campaign's setup tab, click **Add Message**.
    2. On the Select Message Type popup, select **In App Notification**.
    3. In the Setup tab of the App Notification page, enter a Display Name for the in app notification.
    4. Select a Delivery Method. See [Set up message delivery](/campaigns/create/add-message/set-up-message-delivery) for guidance.
    5. Click **Save**.
  </Expandable>

  <Expandable title="Configure video" default-open="false">
    A video is an embedded piece of video content included with a campaign. A video allows you to define what static images are displayed before and after the customer plays the video content, and has the option of including a destination URL or deeplink.

    1. From the campaign's setup tab, click **Add Message**.
    2. On the Select Message Type popup, select **Video**.
    3. On the Setup tab of the Video page, enter a Display Name for the in app notification.
    4. Click **Save**.
  </Expandable>

  <Expandable title="Issue bulk offer" default-open="false">
    Bulk offers are sent to each member of the target audience.

    1. From the campaign's setup tab, click **Add Message**.
    2. On the Select Message Type dialog, select **Issue Bulk Offer**.
    3. On the Setup tab of the Issue Bulk Offer page, select a Delivery Method. See [Set up message delivery](/campaigns/create/add-message/set-up-message-delivery) for guidance.
    4. Click **Save**.
  </Expandable>
</ExpandableGroup>
