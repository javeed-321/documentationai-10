Specify advanced settings that allow data to be passed to another vendor.

## Steps

1. In the Advanced Settings area of the Setup tab, click **Edit Settings** to display the Advanced Setting panel.
2. In the Campaign Permalink field you can specify a permanent, static hyperlink for campaign.
3. If you want to pass provide another vendor with data, you can pass a key-value pair - as a valid JSON object - in the Custom Payload field.
4. If you want to allow an organization to enter the "Parent Campaign ID" so that reporting gets merged across multiple campaigns in their 3rd party reporting vendor's platform, click **Toggle Basic Mode**.
5. Click **Save**.

The new settings display in the Advanced Settings area on the campaign builder page.
