View basic information such as list name, code type, start and end dates, and usage metrics.

## Steps

On the SessionM landing page under Loyalty, select **Promo Codes**.

## Detailed Information

The Promo Codes Lists dashboard displays the following information:

- **Promo Code List Status** – Status of promo code list is indicated with a tag that appears in the dashboard. Statuses include:
  - **Active** – Promo code list is currently in a valid, activated status. If a platform user applies a promo code against this list, it is awarded. The current date is within the start and end date range.
  - **Pending** – Promo code list is before start date and pending activation.
  - **Completed** – Promo code list has successfully completed, the end date has passed, or the code cap has been reached.
- **Promo Code List Name** – Internal identifier for the promo code list. This field is searchable.
- **Promo Code Type** – Either "single use," "multi use" or "3rd party."
- **List Start and End Dates** – Dates that activate the promo code list and allow a customer to redeem a code associated with the list.
- **Claim Count** – Number of promo codes claimed within the promo code list.
- **Entry Cap** – Number of times a specific code can be claimed.
- **Number of Codes** – Number of promo codes created within a promo code list.
