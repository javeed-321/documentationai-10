title: "View promo code details"
description: "View detailed information about a specific promo code, including generation batches and the change log."
---

View information about a specific promo code.

- For a single-use code, the returned information includes promo codes details, a code generation batch, and a change log.
- For a multi-use promo code, the returned information includes promo code details and a change log.

## Steps

On the All Promo Codes List view, select the promo code for which you want to view detailed information.
