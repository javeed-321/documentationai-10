---
title: "How do I create or import a policy?"
description: "Start from a template, write your own, or bring an existing document in."
---

There are three ways to get a policy into Scrut.

## Start from a template

- Pick a template, then edit it to match how your organization actually works.

## Write one from scratch

- Create a blank policy and use the editor to build it out.

## Import an existing document

- Upload a file or import from connected storage. Formatting is preserved where possible.

<Callout kind="tip">
  Templates are a starting point, not a finished policy. Auditors look for evidence that a policy reflects real practice.
</Callout>
