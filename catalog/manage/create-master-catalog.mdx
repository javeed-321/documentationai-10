Create a master catalog from a store catalog.

## About this task

This task can be accomplished from the Store Mappings tab, which displays only for Disparate Catalog scenarios.

## Steps

1. In the Store Catalog section of the Store Mappings tab, specify the location of the store catalog using the **Select Store** dropdown.
2. Then in the Master Catalog section, click on the **Clone Store Catalog** link. The Please Confirm dialog displays, prompting you to clone the store catalog for the new master catalog.
3. Click **Clone**.

The master catalog is cloned and now appears in the Master Catalog section of the tab.
