Search and view the categories and items in a master or store catalog.

## About this task

Your ability to search and view a catalog depends on the type of catalog you are working with:

- In unified catalogs, only master catalogs can be accessed.
- Disparate catalogs, on the other hand, contain tabs for both master and store catalogs.

From the Master or Store Catalog tab in a disparate catalog as well as the master catalog displaying for a unified catalog, you can simply scroll through the categories listed in the table looking for a specific category. Once located, click on a category to see the items it contains. Or, alternatively, you can use the available search bar detailed below.

## Steps

1. If you need to see where a specific category or item resides in the catalog hierarchy or you want to review/edit a category or item, enter the desired query criteria in the **Search** field to locate the node(s) of interest. The filtered results display in Search Results. Any categories meeting the query criteria display in the left hand column; any items meeting the query criteria display in the right hand column.
2. In the Store Catalog tab, the categories and items that appear are for the location shown in a gray box that displays at the top of the Categories column. If you want to change that location and see categories and items for another store, click the gray box containing the location name. Then, use the Choose Location dialog to select a new store location.
3. If you want to refine the search results in Master or Store Catalog tabs for disparate catalogs, click either the **All Items tab** to see all items meeting the search criteria or the **Errors Only** tab to see only those items that met the search criteria but generated errors.
