Edit categories and items manually in a disparate master catalog. Editing categories or items in a unified master catalog is possible only through an upload of a newly edited catalog.

## About this task

From the Master Catalog tab of the Catalog Management Module, you can edit the settings for any category or item in a disparate master catalog.

## Steps

1. On the Master Catalog tab, locate the category or item you want to modify in the master catalog.
2. Click either the **Edit category attributes** or **Edit item attributes icon** next to the category or item you want to edit. The Edit Category or Edit Item dialog opens.
3. Add or modify the existing values in any of the fields on the dialog.
4. Click **Save**. The system saves the new data for the category or item.

If you are done editing categories or items in the master catalog and want the changes to be applied to all platform modules, click **Publish**.
