Add categories or items manually to an existing category in any disparate master catalog. Adding new categories or items to a unified master catalog is possible only through an upload of a new catalog, or version of a catalog.

## About this task

New categories or items can be added to an existing category, including the Root category. However, once a category contains a sub-category, it cannot contain items at its root level; any new items must be added to one of the category's sub-categories.

## Steps

1. On Master Catalog tab, locate the category that will contain the new category or item.
2. Click the appropriate link:
   1. For a new category, click **+** in the Categories column. In the Create Category dialog, enter identifying information for the category in the Name and Description fields. You can also select a new top level parent in the Parent field.
   2. For a new item, click **+** in the Items column. In the Create Item dialog, enter identifying information for the item in the Name, Description, and SKU fields. You can also select a new top level parent in the Parent field.
3. Click **Save**. The new category or item appears under the parent category.

If you are done adding categories or items to the master catalog and want the changes to be applied to all platform modules, click **Publish**.
