Applicable to Chrome and Edge Browsers

## 1. Overview

algoScraper, available as a extension for web applications, captures all User Interface (UI) elements and their corresponding XPaths. algoScraper can also be used in VM environment.

## 2. Prerequisite

To integrate this tool into your Chrome or Edge browser, Click [**here**](https://chromewebstore.google.com/detail/algoscraper/jalheggejiokjibkjhegkbabogmgnlmm?pli=1). Select the  icon corresponding to the extension to view it on your browser bar, as shown:
