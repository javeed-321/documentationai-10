## **User List**

Below the summary cards, the **User List** section displays all registered users in a tabular format. The table includes the following columns:

| **Column**        | **Description**                                                                                                                                                                                                                                                   |
| ----------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Email**         | The registered email address of the user. This serves as the unique identifier for each user account on the platform.                                                                                                                                             |
| **Department**    | The department or team the user belongs to (e.g., Design, Finance).  If no department is assigned, it appears as `--`.                                                                                                                                            |
| **Status**        | Indicates the current account state of the user either **Active** (user has access to the platform) or **Deactivated** (access has been temporarily disabled).                                                                                                    |
| **Last Modified** | Shows when the user's account was last updated or modified (e.g., role change, profile edit).  Displayed as relative time such as _2 hours ago_, _1 week ago_, etc.                                                                                               |
| **Role**          | The permission level assigned to the user. Roles control what actions a user can perform on the platform:  * **Administrator** (full access)
* **Editor** (can edit and interact with content)
* erer
* **Reader** (read-only access)                      &#x20; |
| **Actions**       | Provides quick controls to manage the user directly from the list:  * **Edit** icon to update user details
* **Deactivate** / **Reactivate** icon to disable or restore user access
* **Delete** icon to permanently remove the user                              |
