| Parameter                   | Type    | Description                        |
| --------------------------- | ------- | ---------------------------------- |
| `apiConfig`                 | Object  | Root API configuration object.     |
|   • `authentication`        | Object  | Authentication settings.           |
|     -- `oauth`              | Object  | OAuth configuration.               |
|       --- `tokens`          | Object  | Token management settings.         |

|     -- `baseUrl`            | String  | Base URL for all API requests.     |
|     -- `rateLimiting`       | Object  | Rate limit configuration.          |
|       --- `maxRequests`     | Integer | Maximum requests per window.       |
|       --- `windowMs`        | Integer | Time window in milliseconds.       |
|         ---- `retryAfter`   | Integer | Seconds to wait after limit hit.   |
|         ---- `backoffType`  | Enum    | `linear` or `exponential` backoff. |
