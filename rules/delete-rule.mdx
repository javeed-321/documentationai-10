Delete a rule from the Rule Management module in the SessionM platform.

## About this task

Deleting a rule remove that rule from the SessionM platform. That rule is no longer available for use in loyalty programs. If you attempt to delete a rule that is currently in use in a loyalty program, SessionM warns you before deleting the rule.

## Steps

1. On the Rules Management dashboard, click the Additional Tasks icon and select **Delete**.

2. Click **Delete** to confirm the deletion.
