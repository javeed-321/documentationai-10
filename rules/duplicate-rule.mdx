Duplicate (and rename) an existing rule in the Rules Management module of the SessionM platform.

## About this task

Duplicating a rule allows you to use an existing rule as a template and then change specific parameters to create a new rule.

## Steps

1. On the Rules Management dashboard, click the Additional Tasks icon and select **Duplicate**.

2. Click on the Pencil icon to the right of the rule name and rename the rule.

3. Adjust the loyalty programs and tier levels where the duplicated rule is used. Click on the value to the right of the Rules Used in label to display the Rules Usage panel. Make any needed changes and click **Done**.

4. Make any desired changes to conditions and outcomes in the rule.

5. Click **Save**.
