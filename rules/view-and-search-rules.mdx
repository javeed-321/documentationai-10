---
title: "View and search rules"
description: "List the defined rules in the Rules Management module, filter them, or search for a specific rule."
---

List the defined rules in the Rules Management module of the SessionM platform. Alternatively, search for a rule by specifying search criteria.

## View rules

Navigate to the Rules dashboard to see a list of defined rules. You can filter the list using the **Loyalty Program** and **Rule Type** dropdown lists.

## Search rules

On the Rules dashboard, enter the search criteria in the "Search for a rule" text box. The SessionM platform applies the search criteria as you type and lists relevant results.
