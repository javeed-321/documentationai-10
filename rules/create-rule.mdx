Create a rule in the Rules Management module.

## Prerequisites

- If the rule is intended to be part of a tiered loyalty program, make sure that the loyalty program has been defined in the SessionM Loyalty Programs module.

## Step 1. Name condition and select rule type

1. Navigate to the Rules dashboard in the Rules Management module and click **Create Rule**.

2. On the Create Rule panel, name the rule.

3. Select the rule type.

4. Optional. Select the loyalty program and tier where this rule will be used.

   Note that you can select more levels/tiers by clicking **+Add Additional Program/Level**.

5. 5. Click **Create**.

## Step 2. Build condition

1. Click or drag the desired condition type from the **RULE CONDITIONS** list onto the **Drag rule conditions here** area. Select the condition from the dropdown list and supply values for each variable in the condition. If needed, add constraints for this condition.

   Note that, for purchase rules, a current purchase event is included by default. For event rules, a current event is included by default.

2. Add additional condition types (with conditions and constraints) if needed.

3. If you have multiple conditions, set the ALL/ANY and AN/OR operations to configure how the conditions are evaluated.

## Step 3. Define outcome

1. Click or drag the desired outcome from the **OUTCOMES** list onto the **outcomes here** area. Supply a value for each variable in the outcome.

2. Add additional outcomes if needed.

## Step 4. Save rule

Click **Save**. The rule is now listed on the Rules page.
