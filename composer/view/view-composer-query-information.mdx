View information about queries created in the Composer module.

## View information about all queries

Use the **Queries** view from the main Composer module dashboard to view all queries that have been created in this module:

<Image src="https://docs.sessionm.com/Resources/Images/Procedures/comp_view_query.gif" width="1366" height="500" alt="Queries view listing all queries created in the Composer module" caption="" />

- **Name**: The name of the query. Clicking this will take you to the Query Editor, where you can make edits, run the query, and/or create an export.

- **Size**: The estimated number of results from the most recent time the query was run and saved. The results may be referring to number of users, stores, points, etc. depending on how the query was built. Note that the platform is using a quick query to display the size here, so it is not necessarily reflecting the exact number that would be included in an export.

- **Created by**: Who created the query. Hovering over the user's initials will display their full name.

- **Created On**: The date that the query was created. Note that this is not necessarily when query was last run, just when the query was first created.
