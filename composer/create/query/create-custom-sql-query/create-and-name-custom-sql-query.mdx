Create and name a custom SQL query.

## Steps

1. From the Composer module main page, click **Create Query** in the top right corner.

   <Image src="https://docs.sessionm.com/Resources/Images/Procedures/create%20query%20button.gif" width="1576" height="558" alt="Create Query button in the top right corner of the Composer module main page" caption="" />

2. In the pop-up, provide the query with a unique name, click **Create**, and you'll be brought to the Query Editor page.

3. Be sure to save your query upon initial creation by clicking the **Save** button.

   <Image src="https://docs.sessionm.com/Resources/Images/Procedures/comp_CreateNameQuery3.gif" width="1582" height="544" alt="Save button on the Query Editor page" caption="" />

**Note**: You can always change the name of the query if needed by clicking the pencil icon at the top of the Query Editor page. Just remember to Save the query after making any edits.
