---
title: "Create custom SQL query"
description: "Use the Composer module to create custom SQL queries that run essential custom extracts from the Data Cloud."
---

Use the Composer module to create custom SQL queries to run essential custom extracts, which you can then export and send to other client systems. The Composer module runs queries from data stored in the Data Cloud, which refreshes once daily.

Note that this is a different functionality from using an SQL query to build an audience in this module. For this functionality, see [Create new Composer audience](/composer/create/audience/create-new-composer-audience/overview).

## Steps

1. [Create and name custom SQL query](/composer/create/query/create-custom-sql-query/create-and-name-custom-sql-query)
2. [Build and run custom SQL query](/composer/create/query/create-custom-sql-query/build-and-run-custom-sql-query)
