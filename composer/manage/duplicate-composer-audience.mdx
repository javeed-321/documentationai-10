title: "Duplicate Composer audience"

---

Duplicate a Composer audience.

## Steps

1. From the Audiences view of the dashboard, click the quick action button in the table row that contains the audience that you want to duplicate, and then select **Duplicate**.

   <Image src="https://docs.sessionm.com/Resources/Images/Procedures/duplicatebutton.PNG" width="1787" height="496" alt="Quick action menu on a Composer audience row with Duplicate selected" caption="" />

2. This directs you to the builder page of the duplicated audience, which is in a draft state. You can verify it is the duplicate as it has 'Copy' appended to its name. Modify the name if desired by clicking the pencil icon next to the audience name.

   <Image src="https://docs.sessionm.com/Resources/Images/Procedures/duplicatechangename.PNG" width="1783" height="512" alt="Renaming the duplicated audience on the builder page" caption="" />

3. Remember to Save any changes you've made to the name and/or the attribute cards by clicking 'Save' under the 'More Actions' dropdown.

   <Image src="https://docs.sessionm.com/Resources/Images/Procedures/duplicatesave.PNG" width="1781" height="525" alt="Save option under the More Actions dropdown" caption="" />

The duplicate audience will now display in the Audiences table in a draft state until you are ready to activate.
