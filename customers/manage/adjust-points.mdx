Adjust loyalty points balance for a customer.

## About this task

The Incentives Point Balance section of the profile header provides information on the customer's total points by the different point accounts as their current balance in each point account and their lifetime earned-to-date level.

## Steps

1. In the Incentives Point Balance section of the Customer Profile Header, click **Adjust**.
2. Complete the following steps on the Adjust Points modal:
   1. Click either **Add** or **Deduct** to adjust points. Enter the number of points in the field to the right of the button.
   2. Select the Point Source. This dropdown displays the different point sources. Select the primary point source for comping points.
   3. Select the Point Account. This dropdown displays the different point accounts. Select the primary point account for comping points.
   4. Reason Code.
   5. Reference ID.
3. Click **Save**.
