Add a customer profile or test persona to the Customer module.

## About this task

In most cases, customers are added to the Customer Module by an external ingest mechanism that bulk loads customer information into the SessionM platform. For example, you can integrate your existing customer relationship management (CRM) information with the SessionM platform. Contact SessionM for steps to enable this integration.

You can also add a customer to the customer base manually. For example, you can define a test persona that allows you to verify that campaigns, loyalty rules and messaging are accurately targeted and personalized. Once a loyalty activity is targeted to the test customer persona, you can then log into SessionM using these test personas to test the customer experience.

## Steps

1. Click **Add Customer** in the top navigation bar of the Customers dashboard.
2. Enter the following customer information.

   | Field | Description |
   | --- | --- |
   | First Name | **Required**. Customer first name. |
   | Last Name | **Required**. Customer last name. |
   | Email | **Required**. Customer email. |
   | Birthday | **Required**. Customer birthday in MM/DD/YY format. |
   | External ID | String used to identify the customer in external systems. |
   | Country | Customer homeland. |

3. If you are adding a profile that will be used for system testing, click the **Is this a test customer persona?** checkbox.
4. Click **Save**.
