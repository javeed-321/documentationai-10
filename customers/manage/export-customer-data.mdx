Submits an export data request, which returns a CSV file of the customer's data.

## About this task

Submits an export data request, which returns a CSV file of the customer's data that you can download and send to the customer. The exported CSV files contain data from a customer profile as well as any data derived from calculated metrics, purchases, marketing and loyalty program-related events, and application sessions. This feature facilitates compliance with the GDPR data subject Right to Data Access and Portability.

## Prerequisites

This workflow is initiated by an end customer submitting a data access request to your company. You must then work through your validation process and determine that the request is legitimate. (The validation process not determined by SessionM).

## Steps

1. Retrieve the end customer profile on the Search For Customers page in the Customers module.

2. Navigate to the Data Privacy section and click **Data Access**.

   You are prompted to confirm that the end customer's identity has been validated.

3. Check **I have verified the customer's identity** and click **Export**.

   You are prompted to confirm the export.

4. Click **Yes, Export**.

   SessionM processes the request and updates the Current Data Privacy Status first to "Export Data - In Progress" and then to "Export Data - Completed" when the data file is ready for download. No notification is sent to you. Instead, you must monitor the status to know when the data file is ready for download. It will be available within 48 hours .

5. Click **Download Report** when the file is ready.

6. Outside of SessionM, combine the downloaded data with data privacy related information gathered from other systems and deliver it to the customer.
