Add a note to a customer profile. Use notes to record key interactions and other important information that you can refer back to during customer calls.

## About this task

The Notes tab displays a list of any notes added previously. The list shows the date and time of each note, the reason for the note, the name of the commenter and the text of the note itself. You can edit existing notes by clicking on the pen icon to the far right of each note listed. Once you edit your note and save your changes, the note is marked as having been edited.

## Steps

1. From the customer profile page, click the **Notes** tab.
2. Select the reason for the note from the Select Reason list.
3. Record the text for the note in the textbox.
4. Click **Add Entry**. The new note appears at the bottom of tab, along with its date/time stamp, its associated "reason" category, and the name of the user logged into the platform, composing the note.

You can click the **pencil icon** to edit the note. You can click the **trash icon** to delete the note.
