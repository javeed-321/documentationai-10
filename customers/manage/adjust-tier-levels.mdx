Adjust the tier level for a customer.

## About this task

When a customer has met the initial requirements for base tier level entry, that tier is displayed in the Incentives Tier section of the Customer Profile header. Clicking on the blue "i" icon opens a modal that provides more details about the customer's current status, including the tier entrance date and progress towards the next tier.

## Steps

1. In the Incentives Tier section of the Customer Profile header, click **Adjust**.
2. Complete the following steps on the Adjust Tiers modal:
   1. Select the Tier System.
   2. Select the Tier Level. This dropdown lists all the different point sources. Select the primary point source for comping points.
   3. Award the user any outcomes associated with entrance to this tier.
   4. Award the user any outcomes associated with intermediate tiers she might be bypassing
3. Click **Save**.
