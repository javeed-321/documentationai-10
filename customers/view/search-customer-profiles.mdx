---
title: "Search customer profiles"
description: "Search for customer profiles by name, email, phone, customer ID or date of birth, and refine the results."
---

Search for one or more customer profiles stored in SessionM platform. You can search by the following fields:

- First Name
- Last Name
- Email Address
- Phone Number
- Customer ID
- Date of Birth

## About this task

Take note of the following considerations when performing a search:

- You can enter either a full name or partial name for the First Name and Last Name fields. For example, if you entered "sam" for the first name, you see results for every user whose first name begins with "sam" (for example, Samantha and Samuel).
- You can enter multiple values on the initial search, or you can refine a search once it has been submitted. For example, if you search on date of birth and receive multiple results, you could then refine the search by entering a value into the first and/or last name fields.

The search results are initially sorted in alphabetical order, but you can resort the list by the customer's first name, last name, telephone number, or email. You also have the option to choose how many results you view per page: 25, 50, 100, or 200. If there is only one match for your search, you are taken directly to the customer's profile.

## Steps

1. Click **Search Customers** in the top navigation bar of the Customers dashboard.
2. On the Search for Customers view, enter the search criteria and click **Search**.

- If there is exact match for your search, that customer profile displays.
- If there are multiple matches, the matching profiles are returned in a list. You can select a profile from the list, or enter additional criteria to refine the search.
- If you need to start again, click **Clear form**.
